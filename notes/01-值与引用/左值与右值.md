# 左值与右值

值类别描述的是**表达式**，不是单纯按对象是否有名字划分。

```cpp
std::string a = "hello";
a;                      // 左值（lvalue）：标识已有对象
std::string("hello");   // 纯右值（prvalue）：用于产生新值
std::move(a);            // 将亡值（xvalue）：仍标识 a，但允许资源被移动
```

右值包括 prvalue 和 xvalue。初学时可以把左值理解为“标识对象的表达式”，把右值理解为“临时值或允许被消耗的表达式”。

`a` 可以反复使用，也可以通过 `&a` 取地址。临时对象通常在包含它的完整表达式结束时销毁；引用绑定等场景可能延长其生命周期。

并非所有左值都有名字：例如 `*ptr` 也是左值；也并非右值都没有身份：`std::move(a)` 是 xvalue。

## 为什么要区分

因为对于下面两个对象：

```cpp
std::string a = "hello";

std::string("world");
```

程序员对它们的态度其实不一样。

对于：

```cpp
a
```

你通常不希望函数把它内部的数据抢走，因为后面还可能继续：

```cpp
std::cout << a;
```

但是：

```cpp
std::string("world")
```

本身就是临时对象。

马上就要销毁了。

那么它内部申请的内存：

```text
"world"
```

与其复制一遍，不如直接拿走。

这就是 move semantics 的出发点。

# 左值引用与右值引用

## 左值引用 `T&`

你之前应该见过：

```cpp
void Foo(std::string &s)
```

这里：

```cpp
std::string &
```

叫：

> lvalue reference

它主要绑定到 lvalue。

例如：

```cpp
std::string a = "hello";

Foo(a);
```

OK。

可以想成：

```text
a
│
│ reference
▼
s
```

`s` 就是 `a` 的别名。

---

但是：

```cpp
Foo(std::string("hello"));
```

通常不行，如果参数是：

```cpp
std::string &
```

因为普通 non-const lvalue reference 不允许绑定一个临时 rvalue。

---

## 右值引用 `T&&`

现在：

```cpp
void Foo(std::string &&s)
```

这里：

```cpp
std::string &&
```

表示：

> 我要接收一个 rvalue。

于是：

```cpp
Foo(std::string("hello"));
```

可以。

因为：

```cpp
std::string("hello")
```

是临时对象，是 rvalue。

---

但：

```cpp
std::string a = "hello";

Foo(a);
```

通常不可以。

因为：

```cpp
a
```

是 lvalue。

函数要求：

```cpp
std::string &&
```

也就是：

> 给我一个“可以被消耗掉”的右值。

而 `a` 是一个正常存在的对象。

---

## 绑定规则

你可以把：

```cpp
&
```

和：

```cpp
&&
```

先这样理解：

| 写法         | 意思                  |
| ---------- | ------------------- |
| `T&`       | 我引用一个正常存在的对象        |
| `const T&` | 我只读地引用一个对象，也可以接临时对象 |
| `T&&`      | 我引用一个“可以被消耗/搬走”的对象  |

例如：

```cpp
void F(std::string &x);
void G(const std::string &x);
void H(std::string &&x);
```

然后：

```cpp
std::string s = "hello";
```

调用：

```cpp
F(s);                    // OK
G(s);                    // OK
H(s);                    // ❌
```

但是：

```cpp
H(std::move(s));         // OK
```

临时对象：

```cpp
F(std::string("hello")); // ❌
G(std::string("hello")); // OK
H(std::string("hello")); // OK
```

---

## 有名字的右值引用表达式仍是左值

看：

```cpp
void Foo(std::string &&s) {
    ...
}
```

虽然 `s` 的类型是：

```cpp
std::string&&
```

但在函数体内部写：

```cpp
s
```

**`s` 这个表达式本身是 lvalue。**

为什么？

因为它有名字。

记住这个规则：

> 有名字的变量，即使类型是 `T&&`，当你直接使用这个名字时，它仍然是 lvalue expression。

所以：

```cpp
void Foo(std::string &&s) {
    Bar(s);
}
```

这里传给 `Bar` 的：

```cpp
s
```

被当作 lvalue。

如果你还想继续 move：

```cpp
Bar(std::move(s));
```

这也是为什么 move constructor 经常长这样：

```cpp
MyClass(MyClass &&other)
    : member_(std::move(other.member_)) {
}
```

因为：

```cpp
other
```

虽然声明是：

```cpp
MyClass&&
```

但 `other.member_` 这个表达式仍然来自一个有名字的 `other`。

所以通常需要再次：

```cpp
std::move(other.member_)
```

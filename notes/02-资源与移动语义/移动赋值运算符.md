# 移动赋值运算符

和 move constructor 很像，但场景不同。

Move constructor：

```cpp
Buffer b(std::move(a));
```

这里：

```text
b 还不存在
```

所以是在：

```text
construct b
```

---

Move assignment：

```cpp
Buffer b(100);

b = std::move(a);
```

这里：

```text
b 已经存在
```

所以必须先：

```text
释放 b 原来的资源
```

再获得 `a` 的资源。

例如：

```cpp
Buffer &operator=(Buffer &&other) {
  if (this != &other) {
    delete[] data_;

    data_ = other.data_;
    size_ = other.size_;

    other.data_ = nullptr;
    other.size_ = 0;
  }

  return *this;
}
```

区别：

```text
Move Constructor

不存在 b
↓
创建 b


Move Assignment

b 已存在
↓
清理 b
↓
接管 a
```

## 注意事项

这里的 `Buffer` 代码是类内部的实现片段，需与析构函数及拷贝策略一起设计。对本例这种不会抛异常的资源转移，可将签名声明为 `Buffer &operator=(Buffer &&other) noexcept`。自移动检查避免先释放自己的资源再接管已失效的指针。

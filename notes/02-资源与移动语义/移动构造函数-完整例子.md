可以。下面这个例子专门演示这一句：

```cpp
MyClass(MyClass &&other)
    : member_(std::move(other.member_)) {}
```

我会让 `member_` 用一个 `std::string`，这样你能直接看到：为什么 `other.member_` 还要再 `std::move()`。

```cpp
#include <iostream>
#include <string>
#include <utility>

class MyClass {
 public:
  // 普通构造函数
  explicit MyClass(std::string value)
      : member_(std::move(value)) {
    std::cout << "constructor\n";
  }

  // 拷贝构造函数
  MyClass(const MyClass &other)
      : member_(other.member_) {
    std::cout << "copy constructor\n";
  }

  // 移动构造函数
  MyClass(MyClass &&other) noexcept
      : member_(std::move(other.member_)) {
    std::cout << "move constructor\n";
  }

  void Print(const std::string &name) const {
    std::cout << name << ".member_ = \"" << member_ << "\"\n";
  }

 private:
  std::string member_;
};

int main() {
  MyClass a("hello world");

  std::cout << "\nBefore move:\n";
  a.Print("a");

  MyClass b(std::move(a));

  std::cout << "\nAfter move:\n";
  a.Print("a");
  b.Print("b");

  return 0;
}
```

典型输出类似：

```text
constructor

Before move:
a.member_ = "hello world"

move constructor

After move:
a.member_ = ""
b.member_ = "hello world"
```

这里最值得仔细看的是：

```cpp
MyClass b(std::move(a));
```

整个过程其实有两层 move。

第一层：

```cpp
std::move(a)
```

把 `a` 转成右值，于是匹配：

```cpp
MyClass(MyClass &&other)
```

所以进入移动构造函数。

此时可以理解成：

```text
a
│
│ std::move(a)
▼
MyClass&& other
```

`other` 引用的其实就是 `a`。

但问题来了。

在移动构造函数里面：

```cpp
MyClass(MyClass &&other) noexcept
    : member_(std::move(other.member_)) {
}
```

为什么不能直接写：

```cpp
member_(other.member_)
```

因为虽然 `other` 的类型是：

```cpp
MyClass&&
```

但是：

```cpp
other
```

**是一个有名字的变量。**

只要你在表达式里写：

```cpp
other
```

它就是一个 lvalue。

所以：

```cpp
other.member_
```

也是 lvalue。

因此如果写：

```cpp
MyClass(MyClass &&other)
    : member_(other.member_) {
}
```

实际上调用的是 `std::string` 的 **copy constructor**：

```cpp
std::string(const std::string &)
```

相当于：

```text
a.member_
    │
    │ copy
    ▼
b.member_
```

这就失去了 move constructor 的意义。

所以必须：

```cpp
member_(std::move(other.member_))
```

这样：

```text
other.member_
      │
      │ std::move
      ▼
rvalue
      │
      ▼
std::string(std::string&&)
```

于是 `std::string` 自己的 move constructor 被调用。

可以把整个过程画出来：

```text
MyClass a
┌──────────────────────────┐
│ member_                   │
│      │                    │
│      ▼                    │
│ "hello world"             │
└──────────────────────────┘


MyClass b(std::move(a))
              │
              ▼

调用：

MyClass(MyClass&& other)

其中：

other 其实引用 a


然后：

member_(std::move(other.member_))

                  │
                  ▼

调用 std::string 的 move constructor


结果：

a
┌──────────────────────────┐
│ member_                   │
│ moved-from                │
└──────────────────────────┘


b
┌──────────────────────────┐
│ member_                   │
│ "hello world"             │
└──────────────────────────┘
```

再看一个对比，你会更容易理解。

### 错误/低效版本：忘记 `std::move`

```cpp
MyClass(MyClass &&other)
    : member_(other.member_) {
}
```

这里虽然外层是：

```cpp
MyClass(MyClass &&)
```

但是内部：

```cpp
member_(other.member_)
```

仍然发生：

```text
copy
```

因为：

```cpp
other.member_
```

是 lvalue。

相当于：

```text
a
 │
 │ std::move
 ▼
进入 MyClass move constructor

但是里面：

other.member_
 │
 │ 是 lvalue
 ▼
copy string
```

所以这是一个“名字叫 move constructor，但成员实际上在 copy”的实现。

正确版本：

```cpp
MyClass(MyClass &&other) noexcept
    : member_(std::move(other.member_)) {
}
```

是：

```text
a
 │
 │ std::move
 ▼
MyClass move constructor

other.member_
 │
 │ std::move
 ▼
string move constructor
```

------

我们还可以把例子扩展到多个成员。现实代码通常更像这样：

```cpp
#include <iostream>
#include <string>
#include <utility>
#include <vector>

class User {
 public:
  User(std::string name, std::vector<int> data)
      : name_(std::move(name)),
        data_(std::move(data)) {}

  User(const User &other)
      : name_(other.name_),
        data_(other.data_) {
    std::cout << "User copy constructor\n";
  }

  User(User &&other) noexcept
      : name_(std::move(other.name_)),
        data_(std::move(other.data_)) {
    std::cout << "User move constructor\n";
  }

  void Print() const {
    std::cout << "name = \"" << name_
              << "\", data size = "
              << data_.size() << '\n';
  }

 private:
  std::string name_;
  std::vector<int> data_;
};

int main() {
  User a(
      "Alice",
      std::vector<int>(1'000'000, 42)
  );

  std::cout << "Before move:\n";
  a.Print();

  User b(std::move(a));

  std::cout << "\nAfter move:\n";

  std::cout << "a: ";
  a.Print();

  std::cout << "b: ";
  b.Print();
}
```

这里：

```cpp
User(User &&other) noexcept
    : name_(std::move(other.name_)),
      data_(std::move(other.data_)) {
}
```

表达的就是：

```text
other.name_
    ↓
不要复制 string
直接搬给 name_

other.data_
    ↓
不要复制 100 万个 int
直接搬 vector 内部 buffer
```

尤其 `vector` 很好理解。

原来：

```text
a.data_

vector object
    │
    │ pointer
    ▼
heap
┌──────────────────────────────┐
│ 42 42 42 42 ... 1,000,000个 │
└──────────────────────────────┘
```

如果 copy：

```cpp
User b(a);
```

大概：

```text
a.data_
   │
   ▼
[ 1,000,000 ints ]

       COPY 1,000,000 ints

b.data_
   │
   ▼
[ 1,000,000 ints ]
```

而：

```cpp
User b(std::move(a));
```

大概：

```text
Before:

a.data_
   │
   ▼
[ 1,000,000 ints ]


After move:

a.data_             b.data_
(empty)                 │
                        ▼
                 [ 1,000,000 ints ]
```

核心不是把一百万个整数“搬过去”。

实际上通常只是把 `vector` 内部的几个字段转移：

```text
data pointer
size
capacity
```

所以 move 很便宜。

你现在可以把这句：

```cpp
MyClass(MyClass &&other)
    : member_(std::move(other.member_)) {}
```

直接翻译成人话：

> “我要创建一个新的 `MyClass`，调用方已经允许我消耗 `other`。因此对于 `other` 里面的 `member_`，我也明确告诉 `member_`：不要复制了，把你的资源转移给我的 `member_`。”

最关键的坑就是：

```cpp
other
```

虽然类型是：

```cpp
MyClass&&
```

但因为 **`other` 有名字**，所以：

```cpp
other.member_
```

仍然是 lvalue。

因此必须显式写：

```cpp
std::move(other.member_)
```

才能继续把“可移动”这个语义传递下去。

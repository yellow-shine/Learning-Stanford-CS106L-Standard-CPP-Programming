# 01 · Welcome：先让学习闭环跑起来

[目录](../README.md) · [下一课：类型与结构体](02-types-structs.md)

## 先修与目标

会使用变量、条件、循环和函数即可，不要求记住所有 C++ 语法。本课要分清源文件、编译、链接和执行；以后遇到问题先判断它发生在哪个阶段，而不是不断修改代码碰运气。

CS106L 是现代 C++ 语言课，不是数据库原理课。Spring 2026 的主体教学安排在前八周，七份短作业用来练语言概念。我们的自学节奏不照搬周数：读懂例子后运行一次，隔天再用自己的话解释一次，比只看完课件更可靠。

## 从文字到程序

`.cpp` 是给人和编译器看的源代码，不会直接执行。预处理会处理 `#include` 等指令；编译器检查类型和语法并生成目标代码；链接器把各部分定义组合为可执行文件。下面的 `c++` 命令替你完成这些阶段。

- **编译错误**：如把字符串当整数、漏分号、调用不可见的函数。
- **链接错误**：编译时看过函数声明，但链接时找不到实现，常见原因是漏编译一个 `.cpp`。
- **运行错误**：程序已经产生并启动，实际执行到非法访问或断言失败。
- **逻辑错误**：程序能运行，但得到错误结果；必须用检查发现。

头文件提供声明，`std::` 表示标准库命名空间。`main` 是程序入口；在 `main` 结尾没有显式 `return` 时等价于返回 0。不要把所有 `#include` 当作“安装依赖”：这里使用的都是随编译器工具链提供的标准库。

## 完整示例

源文件：[01-welcome.cpp](../examples/01-welcome.cpp)。

```cpp
#include <cassert>
#include <iostream>

int main() {
    const int lessons = 16;
    assert(lessons > 0);
    std::cout << "Ready for " << lessons << " lessons\n";
}
```

从仓库根目录运行：

```bash
c++ -std=c++17 -Wall -Wextra -Wpedantic examples/01-welcome.cpp -o /tmp/cs106l-01
/tmp/cs106l-01
```

输出 `Ready for 16 lessons`。`assert` 是本课程的最小自动检查：条件不成立会终止程序。它不是对不可信输入的生产级验证，因为定义 `NDEBUG` 后断言会被移除。之后读到输入检查时，我们会用条件判断或异常，而不是只靠断言。

## 版本和工具的边界

本地例子用 C++17，不等于官网止步于 C++17。C++20 增加 ranges、concepts 等，C++23 增加 optional 单子操作。需要某个特性时，编译选项与标准库版本必须同时支持。课程官网提到更近的标准，不表示你为了学习需要立即安装实验编译器。

macOS 上 `g++` 可能实际上是 Apple Clang；看 `c++ --version`，不要只看命令名字。编辑器补全不是编译器，红色波浪线也不是最终结论。这里不要求特定 IDE。

## 易错点与 BusTub 联系

- 修改源文件后必须重新编译，否则运行的是旧程序。
- 运行命令时的工作目录影响相对文件路径；这在官方 CSV 作业中很重要。
- BusTub 有多个源文件，用 CMake 组织编译；不要对项目随手执行 `g++ main.cpp`。
- 先读具体测试的失败信息，再扩大排查范围；“编译成功”不等于“实现正确”。

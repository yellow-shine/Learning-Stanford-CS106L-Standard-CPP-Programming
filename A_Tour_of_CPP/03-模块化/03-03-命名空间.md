# 3.3 命名空间（Namespaces）

## 学习目标

使用命名空间组织名称并避免冲突，理解限定名、`using` 声明和参数相关查找的影响。

## 核心知识点

- **命名空间（namespace）**：为相关声明提供可扩展的名称作用域，同一命名空间可分散在多个文件中定义。
- **限定名（qualified name）**：`lib::name` 明确指出名称来源，是公共和跨模块代码中最稳妥的写法。
- **using 声明（using-declaration）**：如 `using std::string;` 只引入指定名称，影响范围应尽量小。
- **using 指令（using-directive）**：`using namespace` 引入候选集合，放在头文件会污染所有包含者。
- **命名空间别名（namespace alias）**：可为长命名空间提供局部短名，不改变原始接口。
- **参数相关查找（argument-dependent lookup, ADL）**：函数调用还会搜索实参类型所属命名空间，常用于非成员运算符和 `swap`。

## 最小示例

```cpp
#include <iostream>
namespace geometry {
struct Point { int x, y; };
int sum(Point p) { return p.x + p.y; }
}
int main() {
    geometry::Point p{2, 3};
    std::cout << sum(p) << '\n'; // ADL 找到 geometry::sum
}
```

## 常见陷阱

- 在头文件全局作用域写 `using namespace std;`，给包含者制造名称冲突。
- 用命名空间模拟类，暴露并依赖大量可变全局变量。
- 忽略 ADL 导致意外重载参与，或对函数来源判断错误。

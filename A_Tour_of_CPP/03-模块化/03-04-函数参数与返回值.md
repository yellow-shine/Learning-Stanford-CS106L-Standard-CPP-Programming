# 3.4 函数参数与返回值（Function Arguments and Return Values）

## 学习目标

按语义和成本选择值、引用与指针参数，并安全高效地返回结果。

## 核心知识点

- **输入值参数（input by value）**：小型值或需要取得副本时直接传值；调用者可清楚知道函数不会修改原对象。
- **常量引用参数（const reference parameter）**：适合不复制地读取大型对象，但需注意被引用对象的生命周期。
- **输出引用（output reference）**：可修改调用者对象，但调用点不够直观；单一结果通常优先直接返回。
- **空值语义（nullable semantics）**：指针可表达“可能没有对象”；引用通常表示调用期间对象必须存在。
- **按值返回（return by value）**：返回局部对象通常由复制消除或移动优化，无需返回引用来逃避复制。
- **结构化绑定（structured binding）**：可解构结构体、数组或元组，使多结果返回保持命名清晰。

## 最小示例

```cpp
#include <string_view>
#include <utility>

std::pair<std::string_view, std::string_view> split_once(std::string_view s) {
    auto p = s.find(':');
    return p == s.npos ? std::pair{s, std::string_view{}}
                       : std::pair{s.substr(0, p), s.substr(p + 1)};
}
int main() { auto [key, value] = split_once("x:42"); return value == "42" ? 0 : 1; }
```

## 常见陷阱

- 返回局部对象的引用或指针，函数结束后立即悬空。
- 认为按值返回大型对象必然复制，因而引入复杂的输出参数。
- 接受 `std::string_view` 后把它长期保存，却无法保证底层字符存活。

# 18.6 协程（Coroutines）

## 学习目标

理解 C++20 协程是可挂起函数的语言机制，并认识其库接口、寿命和调度边界。

## 核心知识点

- 含 `co_await`、`co_yield` 或 `co_return` 的函数可转换为协程，其状态通常存放在协程帧中。
- 返回类型的 `promise_type` 决定创建、挂起、结果和异常处理；标准并未提供通用 `task` 或 C++20 `generator`。
- `co_await` 通过 awaiter 决定是否挂起、如何安排恢复以及恢复表达式产生什么值。
- 协程本身不等于线程，也不会自动并行；执行器、I/O 框架和取消策略由库或应用提供。

## 最小示例

```cpp
#include <coroutine>
struct Ready {
    bool await_ready() const noexcept { return true; }
    void await_suspend(std::coroutine_handle<>) const noexcept {}
    int await_resume() const noexcept { return 42; }
};
// Ready 展示 awaiter 协议；完整协程还需要带 promise_type 的返回类型。
int main() { return Ready{}.await_resume() == 42 ? 0 : 1; }
```

## 常见陷阱

- 协程参数中的引用可能在恢复前悬空；协程句柄若无人销毁会泄漏帧，过早销毁又会让后续恢复无效。
- `await_suspend` 可能安排协程立即在别处恢复；挂起后再访问协程帧或句柄可能与恢复、销毁发生竞态。

# 18.4 等待事件（Waiting for Events）

## 学习目标

使用条件变量等待状态变化，正确处理虚假唤醒、锁与谓词。

## 核心知识点

- 条件变量让线程在条件未满足时睡眠，避免持续轮询浪费处理器。
- `wait(lock,predicate)` 会在检查条件与休眠之间正确配合互斥量，并自动重复处理虚假唤醒。
- 共享条件必须在同一互斥量保护下读取和修改；通知只是提示重新检查，不保存“事件次数”。
- 超时等待使用 `wait_for` 或 `wait_until`，到时后仍须依据谓词判断工作是否真的完成。

## 最小示例

```cpp
#include <condition_variable>
#include <mutex>
#include <thread>
int main() {
    std::mutex m; std::condition_variable cv; bool ready{};
    std::jthread producer{[&] { { std::lock_guard lock{m}; ready=true; } cv.notify_one(); }};
    std::unique_lock lock{m}; cv.wait(lock, [&]{ return ready; });
}

```

## 常见陷阱

- 不带谓词只等待一次会被虚假唤醒；先通知后才随意修改条件，也可能让等待者错过正确状态。
- 条件变量不保存通知；谓词状态必须在对应互斥量下修改和检查，否则通知时序正确也无法建立可靠同步。

# 18.2 任务与线程（Tasks and Threads）

## 学习目标

区分工作任务与执行线程，正确启动、等待并传递参数。

## 核心知识点

- `std::thread` 代表一个执行线程，构造即启动；必须在对象销毁前调用 `join()` 或 `detach()`。
- 线程参数默认按值复制或移动；需要传引用时显式使用 `std::ref`，并保证被引用对象活得足够久。
- `std::jthread` 是 C++20 的自动连接线程，并支持协作式停止，通常比裸 `thread` 更安全。
- 任务是要完成的工作，可由线程池或异步设施调度；不必把每个逻辑任务绑定到一个新线程。

## 最小示例

```cpp
#include <cassert>
#include <thread>
int main() {
    int result{};
    std::jthread worker{[&] { result = 42; }};
    worker.join();
    assert(result == 42);
}
```

## 常见陷阱

- 分离线程很容易访问已销毁局部对象；除非有明确的进程级寿命与关闭协议，否则优先结构化等待。
- `hardware_concurrency()` 可能返回零且只是提示，不能把它当作可用线程数的强保证或数组除数。

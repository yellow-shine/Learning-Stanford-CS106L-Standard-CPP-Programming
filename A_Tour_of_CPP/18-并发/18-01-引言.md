# 18.1 引言（Introduction）

## 学习目标

理解并发的目标、执行单元和内存共享风险，建立先正确后并行的设计顺序。

## 核心知识点

- 并发让多个任务在重叠时间推进，并行则指工作真实同时执行；二者相关但并不等同。
- 标准库提供线程、互斥量、条件变量、原子类型和任务结果设施，语言内存模型规定线程间可见性。
- 不可变数据、消息传递与任务分解通常比任意共享可变状态更容易推理。
- 并发只有在工作规模足以覆盖调度与同步成本时才可能加速，必须以测量验证。

## 最小示例

```cpp
#include <iostream>
#include <thread>
int main() {
    std::thread worker{[] { std::cout << "work\n"; }};
    worker.join();
}
```

## 常见陷阱

- 忘记等待仍可连接的 `std::thread` 会在其析构时终止程序；输出已同步也不等于复合消息不会交错。
- 线程数量超过硬件和工作负载所需会增加切换与缓存争用；并发度不是越高越快。

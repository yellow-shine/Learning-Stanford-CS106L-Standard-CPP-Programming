# 18.5 任务通信（Communicating Tasks）

## 学习目标

用 future、promise 与 async 在任务间传递结果和异常，减少直接共享状态。

## 核心知识点

- `promise<T>` 产生一个 `future<T>`，生产者可设置值或异常，消费者通过 `get()` 等待并取得结果。
- `future::get()` 通常只能调用一次；需要多个消费者观察同一结果时可使用 `shared_future`。
- `std::async` 返回 future，但默认启动策略可能延迟执行；需要并发时显式请求 `std::launch::async`。
- 异常可跨任务边界保存并在 `get()` 时重新抛出，使错误处理回到获取结果的一方。

## 最小示例

```cpp
#include <future>
int main() {
    auto answer = std::async(std::launch::async, [] { return 6 * 7; });
    return answer.get() == 42 ? 0 : 1;
}
```

## 常见陷阱

- 忽略 `async` 返回的临时 future 可能让析构等待，意外串行化；还应保证每个 promise 最终交付值或异常。
- `future::get()` 通常只能调用一次；生产者退出而未设值会让消费者收到 `broken_promise`，不能按普通空结果处理。

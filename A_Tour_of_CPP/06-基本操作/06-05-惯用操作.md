# 6.5 惯用操作（Conventional Operations）

## 学习目标

了解类型通常应提供哪些构造、比较、交换和迭代操作，使其能自然融入语言与标准库。

## 核心知识点

- **默认构造**：在“空”或默认状态有合理含义时提供；默认对象也必须满足类型不变量。
- **相等比较**：`==` 应表达稳定的值等价关系，并与 `!=` 保持一致；C++20 可由重写规则补全 `!=`。
- **排序关系**：若类型存在自然全序，可提供 `<=>`；只有偏序时不要伪造全序。
- **交换（swap）**：高效交换可支持泛型算法与赋值实现；成员都可交换时默认的逐成员方式通常足够。
- **容器接口**：提供 `begin()`、`end()`、`size()` 等惯用名称，可让范围 `for` 与标准算法直接使用。
- **显式转换**：布尔状态等转换通常应为 `explicit`，既支持条件判断，又避免意外算术转换。

## 最小示例

```cpp
#include <array>
#include <compare>
struct Version {
    int major{}, minor{};
    auto operator<=>(const Version&) const = default;
};
class PairView {
    std::array<int, 2> a_{};
public:
    auto begin() { return a_.begin(); }
    auto end() { return a_.end(); }
};
```

## 常见陷阱

- 仅为满足容器要求而制造无意义默认状态，会把错误推迟到运行期。
- 比较中忽略参与值语义的成员，可能使关联容器行为令人意外。
- 自定义 `swap` 若可能抛异常，会削弱依赖交换实现的异常保证。

# 6.6 用户自定义字面量（User-Defined Literals）

## 学习目标

理解用户自定义字面量如何为带单位或领域值提供可读写法，并能选择合适的字面量运算符形式。

## 核心知识点

- **用户自定义字面量（user-defined literal）**：通过后缀把源代码中的数值、字符或字符串字面量转换为领域类型。
- **字面量运算符**：声明形式为 `operator""_suffix`；自定义后缀必须以下划线开头。
- **已处理形式**：整数可接收 `unsigned long long`，浮点数可接收 `long double`，字符串可接收指针和长度。
- **原始形式**：以字符序列接收字面量文本，适合自行解析，但需完整验证格式和范围。
- **命名空间**：把后缀置于领域命名空间，调用方通过受控的 `using namespace` 决定是否引入。
- **常量求值**：简单转换可声明为 `constexpr`，使单位换算和检查能够在编译期完成。

## 最小示例

```cpp
struct Distance { long double metres; };
constexpr Distance operator""_km(long double x) { return {x * 1000}; }
constexpr Distance operator""_m(unsigned long long x) {
    return {static_cast<long double>(x)};
}
int main() {
    constexpr auto trip = 1.5_km;
    static_assert(trip.metres == 1500);
}
```

## 常见陷阱

- 后缀过短或含义宽泛容易与其他库冲突，应限定在明确命名空间。
- 整数字面量和浮点字面量调用不同重载，按需同时提供。
- 字面量不应隐藏昂贵运行时工作或模糊的单位转换。

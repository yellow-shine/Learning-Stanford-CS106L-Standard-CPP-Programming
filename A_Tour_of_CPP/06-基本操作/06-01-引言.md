# 6.1 引言（Introduction）

## 学习目标

认识构造、析构、复制、移动和运算符如何共同定义一个类型的基本行为，并理解默认生成操作的价值。

## 核心知识点

- **特殊成员函数（special member function）**：默认构造、复制、移动、析构等操作决定对象的创建、转移与结束方式。
- **默认操作（defaulted operation）**：成员语义正确时，用 `= default` 或隐式生成即可获得一致且高效的逐成员行为。
- **删除操作（deleted operation）**：用 `= delete` 明确禁止不合理的构造、复制或重载调用。
- **资源句柄**：拥有资源的类需定义清晰的复制或移动策略，不能让多个对象意外重复释放同一资源。
- **运算符语义**：重载应保持该符号通常的直觉，例如 `==` 表示等价，`+` 不应修改左操作数。
- **零规则（rule of zero）**：优先把资源交给标准库类型管理，使业务类无需手写析构、复制和移动。

## 最小示例

```cpp
#include <string>
struct User {
    std::string name;
    int score{};
    User() = default;
    User(std::string n, int s) : name{std::move(n)}, score{s} {}
    bool operator==(const User&) const = default;
};
int main() { User a{"Ada", 7}; User b = a; return a == b ? 0 : 1; }
```

## 常见陷阱

- 一旦手工管理资源，依赖浅复制往往会造成重复释放或共享状态。
- 不要因为“可能更快”而到处显式 `std::move`；它会改变源对象状态，也可能妨碍省略复制。
- 自定义运算符不应违反使用者熟悉的代数直觉。

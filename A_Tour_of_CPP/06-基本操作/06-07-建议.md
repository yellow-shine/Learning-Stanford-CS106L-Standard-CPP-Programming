# 6.7 建议（Advice）

## 学习目标

能以最少的自定义代码建立可预测的对象语义，并让编译器和标准库承担资源管理与常规操作。

## 核心知识点

- **遵循零规则**：成员若都是可靠的值类型，优先让编译器生成复制、移动和析构操作。
- **明确复制策略**：类型要么深复制、要么共享、要么禁止复制；不可让裸资源所有权决定偶然行为。
- **廉价移动**：资源句柄的移动应转移句柄而非复制内容，并在真实满足保证时标记 `noexcept`。
- **惯用语义**：运算符与构造转换应符合普遍预期，意外副作用改用具名函数表达。
- **RAII 优先**：每项资源立刻交给一个对象管理，避免取得资源与建立所有者之间出现异常窗口。
- **默认比较**：成员顺序和语义合适时使用默认比较，减少遗漏成员造成的不一致。

## 最小示例

```cpp
#include <string>
#include <vector>
struct Document {
    std::string title;
    std::vector<std::string> lines;
    Document() = default;
    Document(const Document&) = default;
    Document(Document&&) noexcept = default;
    Document& operator=(const Document&) = default;
    Document& operator=(Document&&) noexcept = default;
    bool operator==(const Document&) const = default;
};
```

## 常见陷阱

- 不要无条件给移动操作写 `noexcept`；成员移动会抛出时承诺错误将导致终止。
- 不要同时手写全部五个特殊成员而不先检查标准类型能否代管资源。
- `std::move` 后仍读取源值通常依赖未承诺的状态。

# 6.3 资源管理（Resource Management）

## 学习目标

用 RAII 将资源生命周期绑定到对象生命周期，并用标准容器和智能指针减少手工管理。

## 核心知识点

- **资源获取即初始化（RAII）**：构造时取得资源，析构时释放，使正常返回和异常传播都走同一清理路径。
- **资源（resource）**：不仅是内存，也包括文件、锁、套接字等必须成对获取与释放的实体。
- **独占所有权**：`std::unique_ptr` 表示只有一个拥有者，可移动但默认不可复制。
- **共享所有权**：`std::shared_ptr` 用引用计数共享生命周期；仅在确有共同拥有语义时使用。
- **非拥有观察**：裸指针、引用或 `std::span` 可访问外部对象，但调用者必须保证被观察对象仍然存活。
- **标准容器**：`std::vector`、`std::string` 等已实现资源管理和复制移动语义，通常优于手写动态数组。

## 最小示例

```cpp
#include <fstream>
#include <stdexcept>
#include <string>
std::string first_line(const char* path) {
    std::ifstream in{path};
    if (!in) throw std::runtime_error{"open failed"};
    std::string line;
    std::getline(in, line);
    return line; // in 自动关闭
}
```

## 常见陷阱

- 获取资源后再依赖手写 `release`，遇到早退或异常时容易泄漏。
- `shared_ptr` 形成环会导致引用计数永不归零；反向非拥有关系用 `weak_ptr`。
- 不要用多个独立智能指针接管同一个裸指针。

# 14.5 概念概览（Concepts Overview）

## 学习目标

认识范围相关概念的层级，能用最小必要约束描述泛型算法，并读懂诊断信息。

## 核心知识点

- **`range`**：要求 `ranges::begin(r)` 与 `ranges::end(r)` 可用，是范围体系的基础。
- **输入范围（input_range）**：支持逐项读取；`forward_range` 进一步保证多趟遍历。
- **访问能力**：`bidirectional_range`、`random_access_range`、`contiguous_range` 逐步增加移动或存储保证。
- **`sized_range`**：能以摊销常数时间取得大小，但不等同于连续或随机访问。
- **公共范围（common_range）**：迭代器与哨兵类型相同，便于调用要求同型端点的旧接口。
- **约束组合**：可用 `requires` 合并元素类型和范围能力，避免模板内部才报难懂错误。

## 最小示例

```cpp
#include <ranges>
#include <vector>
template<std::ranges::random_access_range R>
auto middle(R& r) { return r[std::ranges::size(r) / 2]; }
int main() {
    std::vector<int> v{1, 2, 3};
    return middle(v) == 2 ? 0 : 1;
}
```

## 常见陷阱

- `range` 本身不承诺可重复遍历，也不承诺存在 `size()`。
- 约束过强会无故排除合法类型；只声明实现真正需要的能力。
- `sized_range` 与 `ranges::sized_range` 的定制规则不可简单等同于成员 `size()`。

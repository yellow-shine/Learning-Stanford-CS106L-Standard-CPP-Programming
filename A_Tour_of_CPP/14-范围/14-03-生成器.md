# 14.3 生成器（Generators）

## 学习目标

会用 C++20 标准视图按需生成规则序列，并区分有限与无限范围的终止方式。

## 核心知识点

- **生成范围**：生成器按迭代位置计算值，不必先为所有元素分配存储。
- **`iota_view`**：`views::iota(first,last)` 生成递增半开序列；省略终点时得到无界范围。
- **无界范围（unbounded range）**：必须由 `take`、条件或算法哨兵限制，否则遍历不会自然停止。
- **状态与多趟**：生成方式决定是否可重复遍历；不要把所有按需序列都假定为随机访问容器。
- **协程边界**：C++20 有协程语言机制，但标准库没有 `std::generator`；该类型到 C++23 才标准化。

## 最小示例

```cpp
#include <iostream>
#include <ranges>
int main() {
    auto first5 = std::views::iota(1) | std::views::take(5);
    for (int x : first5) std::cout << x << ' ';
}
```

## 常见陷阱

- 对无界 `iota` 直接做完整计数、复制或范围 `for` 会无限运行。
- 递增到整数不可表示范围会产生溢出风险。
- 不要在 C++20 示例中虚构 `std::generator`；自定义协程生成器依赖额外实现。

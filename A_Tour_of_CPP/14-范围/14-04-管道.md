# 14.4 管道（Pipelines）

## 学习目标

能用 `|` 从左到右组合范围适配器，并理解管道只建立描述、不立即处理全部元素。

## 核心知识点

- **管道（pipeline）**：`range | adaptor` 把上一步结果交给下一步，适合表达过滤、变换、截取链。
- **闭包适配器**：`views::take(3)` 等保存参数，随后可与范围组合；这不是一般函数的任意管道运算。
- **融合遍历**：多层视图通常在一次迭代中逐层计算，无需为每一步建立中间容器。
- **顺序语义**：`filter | transform` 与 `transform | filter` 的类型、调用次数和结果可能不同。
- **调试边界**：复杂链可拆成有名称的中间视图，但仍应保证底层对象寿命覆盖最终遍历。

## 最小示例

```cpp
#include <ranges>
#include <vector>
int main() {
    std::vector<int> v{1, 2, 3, 4, 5};
    auto r = v | std::views::filter([](int x) { return x % 2; })
               | std::views::transform([](int x) { return x * 10; })
               | std::views::take(2);
    auto it = r.begin();
    return *it == 10 && *++it == 30 ? 0 : 1;
}
```

## 常见陷阱

- 不要误以为定义管道时 lambda 已经执行。
- 调换适配器顺序可能改变语义，不能只按“看起来等价”重排。
- 管道视图并不自动拥有作为左值传入的源容器。

# 14.6 建议（Advice）

## 学习目标

形成安全使用范围与视图的准则，在表达力、生命周期和接口兼容性之间做清晰取舍。

## 核心知识点

- **范围优先**：当完整序列参与操作时，优先范围算法，减少首尾不配对的机会。
- **视图优先变换**：只需读取流水线结果时用惰性视图；需要所有权、稳定快照或多次随机访问时再物化。
- **寿命显式**：让源容器明显比视图活得久；跨函数返回前确认视图是否拥有数据或属于借用范围。
- **最小概念**：泛型接口采用能支持实现的最弱范围概念，提高复用并改善约束说明。
- **边界适配**：旧 API 需要同型迭代器时，可物化结果或选择 `common_view`，不要强制所有内部接口退回旧写法。

## 最小示例

```cpp
#include <algorithm>
#include <ranges>
#include <vector>
int main() {
    std::vector<int> data{4, 1, 3, 2};
    auto small = data | std::views::filter([](int x) { return x < 3; });
    std::vector<int> saved(small.begin(), small.end());
    std::ranges::sort(saved);
    return saved == std::vector<int>{1, 2} ? 0 : 1;
}
```

## 常见陷阱

- 不要为省一次复制而把悬空视图暴露到对象边界之外。
- 不要假设每个视图都便宜地支持 `size()` 或重复遍历。
- C++20 不提供 `std::ranges::to`，移植代码时检查所用标准版本。

# 14.1 引言（Introduction）

## 学习目标

理解 C++20 范围如何统一序列、约束与算法调用，并掌握惰性视图的基本组合方式。

## 核心知识点

- **范围（range）**：能通过 `begin` 与 `end` 遍历的对象；端点类型可以不同。
- **范围算法**：`std::ranges` 算法可直接接收范围，减少端点不匹配，并支持投影。
- **视图（view）**：轻量、通常不拥有元素的范围表示，可惰性计算过滤或变换结果。
- **适配器（range adaptor）**：`views::filter` 等把范围转换为新视图，常用管道语法组合。
- **概念（concept）**：`range`、`input_range` 等在编译期描述要求，使泛型接口更精确。

## 最小示例

```cpp
#include <iostream>
#include <ranges>
#include <vector>
int main() {
    std::vector<int> v{1, 2, 3, 4};
    auto even = v | std::views::filter([](int x) { return x % 2 == 0; });
    for (int x : even) std::cout << x << ' ';
}
```

## 常见陷阱

- 视图常引用源对象；源对象销毁、移动或失效后不能继续使用。
- 惰性计算意味着副作用可能在遍历时发生，且可能发生多次。
- 并非所有范围都有大小、支持随机访问或能反复遍历。

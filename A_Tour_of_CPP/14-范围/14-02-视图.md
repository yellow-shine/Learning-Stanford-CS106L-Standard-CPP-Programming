# 14.2 视图（Views）

## 学习目标

掌握视图的非拥有、惰性特征，并能判断元素引用、缓存和生命周期是否安全。

## 核心知识点

- **非拥有语义**：许多视图只保存底层范围的引用或迭代状态，创建成本低但不延长源对象寿命。
- **惰性求值（lazy evaluation）**：过滤与变换通常在迭代时执行，不立即生成新容器。
- **元素类型**：视图解引用结果可能是引用、代理或计算出的值，不能一概写成 `T&`。
- **`ref_view`**：左值范围经 `views::all` 可包装为引用视图；合适的右值则可能包装为拥有视图。
- **物化**：C++20 没有通用 `ranges::to`；需要持久容器时可用迭代器显式构造或复制。

## 最小示例

```cpp
#include <ranges>
#include <vector>
int main() {
    std::vector<int> v{1, 2, 3};
    auto squares = v | std::views::transform([](int x) { return x * x; });
    std::vector<int> out(squares.begin(), squares.end());
    return out[2] == 9 ? 0 : 1;
}
```

## 常见陷阱

- 不要返回引用局部容器的视图。
- 对变换视图元素取地址通常不符合预期，因为结果可能是临时值。
- 某些视图会缓存起始位置；底层范围改变后，不应臆测缓存自动更新。

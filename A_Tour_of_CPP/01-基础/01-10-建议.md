# 1.10 建议（Advice）

## 学习目标

把基础语法转化为可执行的编码原则，优先写出类型安全、边界清晰且容易验证的程序。

## 核心知识点

- **直接表达意图（direct expression of intent）**：用合适的类型、标准算法和范围操作描述目标，而非展开底层步骤。
- **初始化优先（initialize first）**：在定义处给对象有效值，缩小未初始化状态和分支遗漏的空间。
- **不可变优先（const by default）**：不需改变的对象和接口使用 `const`，让修改点更醒目。
- **避免裸资源（avoid raw resources）**：普通代码优先使用容器和资源管理对象，不直接配对 `new/delete`。
- **缩小作用域（minimize scope）**：在最接近使用处声明变量，减少状态存活时间与名称冲突。
- **警告与测试（warnings and tests）**：开启高等级编译器警告，并用边界测试验证动态行为。

## 最小示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    const std::vector<int> values{3, -1, 4, -2};
    const auto positives = std::ranges::count_if(values,
        [](int x) { return x > 0; });
    std::cout << positives << '\n';
}
```

## 常见陷阱

- 先写复杂循环再寻找抽象，容易重复标准库已有功能。
- 为少打几个字符滥用全局 `using namespace std;`，引入名称冲突。
- 依赖隐式窄化、未初始化值或不受约束的裸指针来换取表面简短。

# 1.7 指针、数组与引用（Pointers, Arrays, and References）

## 学习目标

掌握连续存储、间接访问与别名机制，理解边界和对象生命周期带来的安全要求。

## 核心知识点

- **指针（pointer）**：保存对象或函数的地址；空指针使用 `nullptr` 表示，可重新指向其他对象。
- **引用（reference）**：对象的别名，定义时必须绑定，之后不能改绑；引用本身不拥有对象。
- **内建数组（built-in array）**：由固定数量的同类型元素连续组成，在多数表达式中会退化为首元素指针。
- **范围遍历（range-based for）**：无需手写下标即可遍历数组或容器；用 `auto&` 可原地修改元素。
- **指针算术（pointer arithmetic）**：只在同一数组对象及其尾后位置范围内有定义。
- **跨度视图（std::span）**：以指针和长度组成非拥有视图，比单独传裸指针更能保留边界信息。

## 最小示例

```cpp
#include <iostream>
#include <span>

void double_all(std::span<int> xs) {
    for (int& x : xs) x *= 2;
}
int main() {
    int a[]{1, 2, 3};
    double_all(a);
    std::cout << a[2] << '\n';
}
```

## 常见陷阱

- 解引用 `nullptr`、悬空指针或尾后指针都会导致未定义行为。
- 把数组传给裸指针参数后，函数无法自动得知元素数量。
- 返回指向局部数组元素的指针或引用。

# 1.2 程序（Programs）

## 学习目标

掌握 C++ 程序的基本组成、入口函数以及从源文件到可执行文件的构建过程。

## 核心知识点

- **源文件（source file）**：源代码通常保存在 `.cpp` 文件中，由预处理、编译和链接阶段共同生成程序。
- **入口函数（entry point）**：托管环境中的程序从 `main` 开始；返回 `0` 表示成功，抵达函数末尾等价于返回 `0`。
- **声明与定义（declaration and definition）**：声明描述名称及类型，定义还提供实体或实现；同一可定义实体通常只能有一个有效定义。
- **头文件（header）**：`#include` 进行文本包含；标准库名称位于 `std` 命名空间。
- **输入输出流（I/O stream）**：`std::cin`、`std::cout` 和 `std::cerr` 提供类型安全的基本输入输出。

## 最小示例

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    if (std::cin >> name)
        std::cout << "Hello, " << name << '\n';
    else
        return 1;
}
```

## 常见陷阱

- 把编译错误与链接错误混为一谈：前者常涉及语法或类型，后者常涉及缺失定义。
- 在头文件中随意放置非 `inline` 的变量或函数定义，导致多重定义。
- 忽略输入流失败状态，继续使用未成功读入的数据。

# 1.1 引言（Introduction）

## 学习目标

理解现代 C++ 的核心取向：以静态类型和零开销抽象表达意图，同时保留对资源与硬件的精确控制。

## 核心知识点

- **多范式语言（multi-paradigm language）**：C++ 同时支持过程式、面向对象、泛型与函数式风格，应按问题选择表达方式。
- **静态类型（static typing）**：多数类型错误在编译期暴露；类型也是接口设计和表达约束的工具。
- **零开销抽象（zero-overhead abstraction）**：未使用的能力不应付费，恰当抽象通常能编译成与手写底层代码相当的实现。
- **资源管理（resource management）**：对象生命周期与析构函数配合，可统一管理内存、文件、锁等资源。
- **标准库（standard library）**：容器、算法、字符串和并发设施应优先于自行实现，减少错误并提高可移植性。

## 最小示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v{4, 1, 3};
    std::ranges::sort(v);
    for (int x : v) std::cout << x << ' ';
}
```

## 常见陷阱

- 把 C++ 当作“带类的 C”，忽略对象生命周期和标准库抽象。
- 为追求底层控制而过早使用裸内存操作，反而损失安全性与可维护性。
- 认为抽象必然更慢；应先写清晰代码，再依据测量优化。

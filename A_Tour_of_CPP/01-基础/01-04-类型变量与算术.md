# 1.4 类型、变量与算术（Types, Variables, and Arithmetic）

## 学习目标

认识基本类型、初始化方式、类型推导与常见算术转换，写出含义明确的表达式。

## 核心知识点

- **对象与类型（object and type）**：类型规定对象可存储的值、可执行的操作以及通常所需的存储布局。
- **初始化（initialization）**：花括号初始化能阻止多数窄化转换，并清楚区分“创建对象”与后续赋值。
- **类型推导（type deduction）**：`auto` 从初始化器推导类型，适合避免重复冗长类型，但不会保留顶层 `const` 和引用，除非显式写出。
- **算术转换（arithmetic conversion）**：混合类型运算会先进行整型提升和通常算术转换，结果类型未必符合直觉。
- **无符号整数（unsigned integer）**：按模运算，不表示负数；与有符号数混算容易出现巨大正值。
- **类型转换（type conversion）**：显式转换优先使用 `static_cast`，以便让意图在代码中可见。

## 最小示例

```cpp
#include <iostream>

int main() {
    int count{7};
    double total{20.0};
    auto average = total / count;
    std::cout << average << '\n';
}
```

## 常见陷阱

- `int x;` 的局部变量可能未初始化，读取它是未定义行为。
- `5 / 2` 执行整数除法，结果为 `2`，赋给 `double` 也不会恢复小数。
- 假设基本类型宽度固定；需要确定位数时使用 `<cstdint>` 中的类型。

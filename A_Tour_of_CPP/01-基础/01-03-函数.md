# 1.3 函数（Functions）

## 学习目标

学会用函数封装操作，并理解参数、返回类型、重载和编译期求值的基本规则。

## 核心知识点

- **函数声明（function declaration）**：名称、参数类型和返回类型共同描述调用接口；定义还包含函数体。
- **值传递（pass by value）**：形参获得实参的副本，适合小型值或需要独立修改的对象。
- **函数重载（function overloading）**：同名函数可用不同参数列表区分，编译器根据可行转换选择最佳匹配。
- **返回类型（return type）**：`void` 表示不返回值；`auto` 可由 `return` 表达式推导，但公共接口常显式写出更清楚。
- **常量表达式函数（constexpr function）**：满足条件时可在编译期求值，也仍可接受运行期参数。

## 最小示例

```cpp
#include <iostream>

constexpr int square(int x) { return x * x; }
double square(double x) { return x * x; }

int main() {
    static_assert(square(4) == 16);
    std::cout << square(1.5) << '\n';
}
```

## 常见陷阱

- 仅凭返回类型不能形成重载，因为调用点无法据此唯一选择函数。
- 返回局部变量的指针或引用会产生悬空对象。
- 对大型只读对象一律值传递可能引入不必要复制；可使用 `const T&`。

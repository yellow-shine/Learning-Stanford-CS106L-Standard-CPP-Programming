# 1.5 作用域与生命周期（Scope and Lifetime）

## 学习目标

区分名称可见范围与对象存在时间，并据此避免悬空引用和意外遮蔽。

## 核心知识点

- **作用域（scope）**：决定名称可在源码哪些位置被查找，包括块、函数、类、命名空间等作用域。
- **生命周期（lifetime）**：表示对象从初始化完成到销毁之间的时间，与名称是否可见不是同一概念。
- **自动存储期（automatic storage duration）**：普通局部对象在控制流到达其声明时初始化并开始生命周期；离开其作用域时按已完成构造的逆序销毁。
- **静态存储期（static storage duration）**：命名空间变量及局部 `static` 对象通常存活到程序结束；局部静态对象首次执行到声明时初始化。
- **名称遮蔽（name hiding）**：内层声明可遮蔽同名外层声明，虽合法但常降低可读性。
- **临时对象（temporary object）**：通常在完整表达式末尾销毁，某些引用绑定规则可延长其生命周期。

## 最小示例

```cpp
#include <iostream>

int next_id() {
    static int id{0};
    return ++id;
}
int main() {
    int x{next_id()};
    { int y{next_id()}; std::cout << x << ' ' << y; }
}
```

## 常见陷阱

- 返回指向局部对象的引用、指针或 `string_view`，离开函数后即悬空。
- 内层变量与外层同名，导致修改的不是预期对象。
- 依赖不同翻译单元中静态对象的初始化或销毁顺序。

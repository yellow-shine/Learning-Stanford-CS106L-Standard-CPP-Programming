# 1.9 映射到硬件（Mapping to Hardware）

## 学习目标

建立 C++ 对象、内存与机器执行之间的基本联系，同时避免把实现细节误当作语言保证。

## 核心知识点

- **对象表示（object representation）**：对象由若干字节构成；`sizeof` 给出其存储大小，包含可能的填充字节。
- **对齐（alignment）**：类型可能要求对象地址满足特定倍数，编译器会在结构布局中插入填充。
- **栈与自由存储（stack and free store）**：这是常见实现模型；标准主要规定存储期，不强制具体硬件区域。
- **机器字节序（endianness）**：多字节值的字节顺序依平台而异，序列化时必须显式约定格式。
- **易失访问（volatile access）**：`volatile` 用于某些内存映射 I/O，阻止特定优化，但不提供线程同步。
- **未定义行为（undefined behavior）**：越界、错误对齐等操作不受语言约束，优化器可假设它们不会发生。

## 最小示例

```cpp
#include <bit>
#include <cstdint>
#include <iostream>

int main() {
    std::uint32_t x{0x01020304};
    std::cout << sizeof(x) << ' '
              << (std::endian::native == std::endian::little) << '\n';
}
```

## 常见陷阱

- 假设 `int` 必为 32 位或结构体成员间没有填充。
- 用 `volatile` 代替原子类型、互斥量或内存屏障处理并发。
- 直接复制对象字节作为可移植文件或网络格式。

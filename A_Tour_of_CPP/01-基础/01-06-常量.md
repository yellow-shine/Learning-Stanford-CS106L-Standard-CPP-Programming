# 1.6 常量（Constants）

## 学习目标

理解 `const`、`constexpr` 与 `consteval` 的职责差异，并用不可变性表达接口约束。

## 核心知识点

- **只读限定（const qualification）**：通过该名称不能修改对象；它不必是编译期常量，也不保证对象绝不会经其他途径改变。
- **常量表达式（constant expression）**：可由编译器在要求编译期值的语境中求值，例如数组界限或 `static_assert`。
- **常量对象（constexpr object）**：必须用常量表达式初始化，且隐含顶层 `const`。
- **立即函数（immediate function）**：`consteval` 函数的调用必须产生编译期结果，适合强制验证常量数据。
- **常量引用（reference to const）**：`const T&` 可绑定常量、非常量及临时对象，并禁止通过该引用修改值。
- **常量正确性（const correctness）**：只读成员函数应标记 `const`，从而可在常量对象上调用。

## 最小示例

```cpp
constexpr int cube(int x) { return x * x * x; }
consteval int checked_cube(int x) { return cube(x); }

int main() {
    constexpr int n = checked_cube(3);
    static_assert(n == 27);
}
```

## 常见陷阱

- 认为 `const` 局部变量一定能用于编译期语境；其初始化器也必须是常量表达式。
- 用 `const_cast` 修改真正的常量对象会产生未定义行为。
- 混淆“指向常量的指针”与“常量指针”的限定位置。

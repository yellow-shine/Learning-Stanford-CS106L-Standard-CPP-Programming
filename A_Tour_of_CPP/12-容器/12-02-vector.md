# 12.2 vector（vector）

## 学习目标

掌握 `std::vector` 的连续存储、增长机制和失效规则，并把它作为动态序列的默认选择。

## 核心知识点

- **连续存储（contiguous storage）**：元素相邻排列，支持常数时间随机访问，并具有良好缓存局部性。
- **大小与容量**：`size()` 是现有元素数，`capacity()` 是无需重新分配可容纳的数量；`reserve` 只增加容量。
- **尾部增长**：`push_back`、`emplace_back` 摊销常数时间；容量不足时会分配新存储并移动或复制元素。
- **中间修改**：插入或删除需移动后续元素，通常为线性时间。
- **访问接口**：`[]` 快但不检查边界，`at()` 检查并在越界时抛异常。
- **失效规则**：重分配使所有指针、引用和迭代器失效；未重分配的插入也可能使插入点及其后的迭代器失效。

## 最小示例

```cpp
#include <vector>
int main() {
    std::vector<int> v;
    v.reserve(3);
    for (int x : {1, 2, 3}) v.push_back(x);
    return v.at(1) == 2 && v.data()[2] == 3 ? 0 : 1;
}
```

## 常见陷阱

- `reserve(n)` 不创建元素，不能随后直接访问 `v[n-1]`。
- 保存元素地址后 `push_back` 可能导致悬空。
- `vector<bool>` 是空间优化特化，其元素访问返回代理而非普通 `bool&`。

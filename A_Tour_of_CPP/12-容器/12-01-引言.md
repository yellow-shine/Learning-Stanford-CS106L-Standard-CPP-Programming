# 12.1 引言（Introduction）

## 学习目标

理解容器以值语义管理元素的共同模型，并能根据访问方式、修改模式和复杂度需求选择容器。

## 核心知识点

- **容器（container）**：容器拥有一组元素并管理其生存期，复制通常复制元素，移动通常转移内部资源。
- **序列容器**：`vector`、`list`、`forward_list` 等按位置组织元素，访问和修改成本各有不同。
- **关联容器**：`map` 按有序键组织，`unordered_map` 按哈希组织，主要面向键查找。
- **迭代器（iterator）**：以统一方式指向元素并描述遍历能力，使算法与具体容器解耦。
- **复杂度保证**：操作具有标准规定的渐近界，但内存局部性和分配成本常决定实际表现。
- **失效规则**：插入、删除和重分配可能使迭代器、指针或引用失效，规则因容器而异。

## 最小示例

```cpp
#include <map>
#include <string>
#include <vector>
int main() {
    std::vector<std::string> names{"Ada", "Bjarne"};
    std::map<std::string, int> score{{names[0], 10}};
    return score.at("Ada") == 10 ? 0 : 1;
}
```

## 常见陷阱

- 不要默认链表插入就更快；找到位置和分配节点也有成本。
- 不要在容器修改后盲目继续使用旧迭代器。
- 容器选择应由主要操作决定，而非元素数量这一项决定。

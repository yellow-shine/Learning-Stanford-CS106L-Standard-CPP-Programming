# 12.5 map（map）

## 学习目标

使用 `std::map` 构建按键排序的关联结构，理解查找、插入、访问和比较器语义。

## 核心知识点

- **有序映射（ordered map）**：元素是 `pair<const Key, T>`，按键的严格弱序排列，迭代会得到排序后的键。
- **唯一键**：`map` 每个等价键只保存一个元素；需要重复键时使用 `multimap`。
- **复杂度**：查找、插入和删除通常保证对数复杂度。
- **访问差异**：`operator[]` 在键不存在时插入值初始化对象；`at()` 不插入并对缺失键抛出异常。
- **插入接口**：`try_emplace` 仅在键不存在时构造映射值；`insert_or_assign` 明确表达插入或覆盖。
- **比较器**：键等价由比较器的双向“不小于”决定，不一定使用 `operator==`。

## 最小示例

```cpp
#include <map>
#include <string>
int main() {
    std::map<std::string, int> counts;
    ++counts["cpp"];
    auto [it, added] = counts.try_emplace("cpp", 9);
    return !added && it->second == 1 ? 0 : 1;
}
```

## 常见陷阱

- 仅查询时使用 `m[key]` 会意外插入；改用 `find`、`contains` 或 `at`。
- 自定义比较器必须满足严格弱序，否则容器行为不可靠。
- 不要修改元素中的键；其类型为 `const Key` 以维护顺序。

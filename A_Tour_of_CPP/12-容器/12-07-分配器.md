# 12.7 分配器（Allocators）

## 学习目标

理解分配器如何把容器的对象管理与原始存储策略分离，并认识 C++20 多态内存资源的适用场景。

## 核心知识点

- **分配器（allocator）**：容器模板参数之一，负责取得和释放未初始化存储；容器仍负责构造与销毁元素。
- **默认分配器**：`std::allocator<T>` 适合绝大多数代码，不应仅为封装 `new` 而自制分配器。
- **分配器感知容器**：复制、移动和交换时是否传播分配器由 traits 决定，这会影响操作成本与合法性。
- **多态分配器**：`std::pmr::polymorphic_allocator` 把资源选择移到运行期，`std::pmr` 提供对应容器别名。
- **内存资源（memory resource）**：`monotonic_buffer_resource` 适合成批分配、整体释放的短生命周期对象；单个释放通常不回收空间。
- **生存期约束**：使用某资源的容器不得比该资源活得更久。

## 最小示例

```cpp
#include <array>
#include <memory_resource>
#include <vector>
int main() {
    std::array<std::byte, 256> buf{};
    std::pmr::monotonic_buffer_resource pool{buf.data(), buf.size()};
    std::pmr::vector<int> v{&pool};
    v.push_back(42);
    return v[0] == 42 ? 0 : 1;
}
```

## 常见陷阱

- 不要为未经测量的性能问题引入自定义分配器复杂度。
- 资源先销毁而容器仍存活会产生未定义行为。
- 单调资源不是通用泄漏修复工具，它依赖明确的批量释放边界。

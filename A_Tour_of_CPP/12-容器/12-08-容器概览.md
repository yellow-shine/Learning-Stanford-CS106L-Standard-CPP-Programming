# 12.8 容器概览（Container Overview）

## 学习目标

比较标准容器的访问、插入、顺序与失效特性，并依据主要工作负载作出可解释的选择。

## 核心知识点

- **连续序列**：`array` 固定长度，`vector` 动态增长，`deque` 支持两端高效操作；连续性和随机访问能力并不完全相同。
- **节点序列**：`list`、`forward_list` 提供稳定节点与局部常数时间修改，以额外内存和较差局部性为代价。
- **有序关联容器**：`map`、`set` 及 multi 版本保持排序，查找和更新通常为对数复杂度。
- **无序关联容器**：哈希容器提供平均常数时间键操作，不提供排序顺序。
- **容器适配器（container adaptor）**：`stack`、`queue`、`priority_queue` 在底层容器上限制接口以表达特定访问纪律。
- **共同接口**：多数容器提供迭代器、`begin/end`、`size/empty` 与插入删除操作，但细节及复杂度不同。
- **默认选择**：动态序列优先考虑 `vector`，键值查找按是否需要排序选择 `map` 或 `unordered_map`。

## 最小示例

```cpp
#include <deque>
#include <map>
#include <vector>
int main() {
    std::vector<int> random_access{1,2};
    std::deque<int> two_ended{2}; two_ended.push_front(1);
    std::map<int,int> ordered{{2,20},{1,10}};
    return ordered.begin()->first == 1 ? 0 : 1;
}
```

## 常见陷阱

- 相同成员名不保证相同失效规则或复杂度。
- 适配器刻意不暴露迭代器，不应绕过其抽象。
- 基准测试应使用接近真实的数据规模与修改模式。

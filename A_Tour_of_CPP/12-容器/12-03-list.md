# 12.3 list（list）

## 学习目标

理解 `std::list` 的双向链式结构、稳定迭代器和拼接能力，并知道何时其成本值得接受。

## 核心知识点

- **双向链表（doubly linked list）**：每个元素位于独立节点，可向前或向后遍历，但不支持随机访问。
- **稳定性**：插入通常不使现有元素的迭代器和引用失效；删除只使指向被删元素者失效。
- **常数时间修改**：已知位置时插入和删除为常数时间；寻找该位置仍可能是线性时间。
- **拼接（splice）**：可在兼容分配器条件下把节点从一个列表转移到另一个，无需复制元素。
- **成员算法**：`sort`、`merge`、`remove`、`unique` 等利用链表结构；通用 `std::ranges::sort` 不适用，因为它要求随机访问。
- **内存成本**：每个节点包含链接并通常单独分配，缓存局部性较差。

## 最小示例

```cpp
#include <list>
int main() {
    std::list<int> a{1, 3}, b{2};
    auto pos = std::next(a.begin());
    a.splice(pos, b);
    return a == std::list<int>{1, 2, 3} && b.empty() ? 0 : 1;
}
```

## 常见陷阱

- 常数时间插入不代表整体性能优于 `vector`。
- `list` 没有 `operator[]`，反复 `advance` 会造成隐蔽的二次复杂度。
- 跨列表拼接应确认分配器兼容要求。

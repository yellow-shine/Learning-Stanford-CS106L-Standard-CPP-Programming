# 17.4 复数（Complex Numbers）

## 学习目标

用 `std::complex` 表示和计算复数，理解算术、极坐标及实虚部访问。

## 核心知识点

- `complex<T>` 按值保存实部和虚部，支持四则运算，并与同一标量类型协作。
- `real()`、`imag()` 读取分量，`abs()` 给出模，`norm()` 给出模的平方，二者含义不同。
- `polar(r,theta)` 从模和弧度角构造复数；`arg()` 返回相角，三角函数单位不是角度。
- 复指数、对数和幂涉及分支切线，边界结果须结合问题域解释。

## 最小示例

```cpp
#include <cassert>
#include <complex>
int main() {
    std::complex<double> z{3.0, 4.0};
    assert(std::abs(z) == 5.0);
    assert(std::norm(z) == 25.0);
}
```

## 常见陷阱

- 把 `norm` 误当作模，或混用角度与弧度；比较计算所得复数时也要考虑浮点误差。
- 复对数、平方根和幂在分支切线附近可能受有符号零影响；不要把某一分支结果误作唯一数学值。

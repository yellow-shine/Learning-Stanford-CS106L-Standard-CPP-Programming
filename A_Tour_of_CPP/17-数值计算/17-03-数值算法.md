# 17.3 数值算法（Numerical Algorithms）

## 学习目标

使用 `<numeric>` 完成归约、扫描和相邻运算，并理解初值与执行顺序的影响。

## 核心知识点

- `accumulate` 按顺序折叠区间，初值同时决定累加器类型，错误初值可能截断结果。
- `reduce` 允许改变组合顺序并可接受执行策略，运算需适应重排；浮点末位可能变化。
- `inner_product` 组合两个序列，`partial_sum` 与 C++17 扫描算法可产生每个前缀的结果。
- 数值算法不负责检查整数溢出、目标区间大小或输入迭代器有效性。

## 最小示例

```cpp
#include <numeric>
#include <vector>
int main() {
    std::vector<double> v{0.5, 1.5, 2.0};
    double sum = std::accumulate(v.begin(), v.end(), 0.0);
    return sum == 4.0 ? 0 : 1;
}
```

## 常见陷阱

- 用整数 `0` 累加浮点序列会在每一步按整数累加；并行归约也不保证与串行逐项相加逐位相同。
- `reduce` 所用操作必须适合重排，目标区间也须足够大；算法不会替调用者验证这些前置条件。

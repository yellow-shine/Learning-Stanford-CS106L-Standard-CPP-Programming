# 17.5 随机数（Random Numbers）

## 学习目标

分离随机引擎与分布，生成可复现且分布语义明确的伪随机序列。

## 核心知识点

- 引擎如 `mt19937` 产生确定的无符号序列；相同种子保证同一标准引擎得到相同序列。
- 分布把引擎输出映射到目标概率模型，例如闭区间均匀整数或正态实数。
- 固定种子适合测试复现；非确定初始化可从 `random_device` 取种，但其熵质量由实现与平台决定。
- 引擎有可变状态；多线程共享同一实例必须同步，通常让每个线程拥有自己的引擎更简单。

## 最小示例

```cpp
#include <cassert>
#include <random>
int main() {
    std::mt19937 engine{42};
    std::uniform_int_distribution<int> die{1, 6};
    const int n = die(engine);
    assert(n >= 1 && n <= 6);
}
```

## 常见陷阱

- 不要用 `rand()%n` 代替分布，它可能有模偏差；也不要在每次取样前重新以低分辨率时间播种。
- 标准分布的映射算法可因标准库实现而异；相同引擎和种子不保证跨实现得到相同的分布结果序列。

# 17.2 数学函数（Mathematical Functions）

## 学习目标

掌握 `<cmath>` 的常用函数、重载和错误边界，避免手写不稳定公式。

## 核心知识点

- `sqrt`、`exp`、`log` 和三角函数对浮点类型提供重载，返回值类型与参数转换有关。
- `hypot` 可比直接计算平方和后开方更好地避免中间溢出或下溢。
- 定义域错误可能产生 NaN，并可按实现与环境设置 `errno` 或浮点异常；不能只依赖一种报告方式。
- 分类函数 `isfinite`、`isnan`、`isinf` 比与特殊值直接比较更可靠。

## 最小示例

```cpp
#include <cassert>
#include <cmath>
int main() {
    const double d = std::hypot(3.0, 4.0);
    assert(d == 5.0 && std::isfinite(d));
}
```

## 常见陷阱

- 不要假定所有数学函数都能在 C++20 常量求值，也不要用 `x == NAN` 检测 NaN；NaN 与自身也不相等。
- 数学函数的错误报告受实现和浮点环境影响；只检查 `errno` 可能漏掉 NaN、无穷或浮点异常。

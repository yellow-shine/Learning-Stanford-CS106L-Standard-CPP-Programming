# 17.7 数值极限（Numeric Limits）

## 学习目标

用 `std::numeric_limits` 查询类型的可移植边界与浮点特征。

## 核心知识点

- `max()` 是最大有限值，`lowest()` 是最小有限值；对浮点类型，`min()` 却是最小正正规值。
- `digits` 描述有效二进制位，`digits10` 描述可无变化往返的十进制位数。
- `epsilon()` 是 1 与下一个可表示值之差，不是适用于所有数量级的万能容差。
- `is_integer`、`is_signed`、`has_infinity` 等成员使泛型代码可按表示能力选择策略。

## 最小示例

```cpp
#include <limits>
static_assert(std::numeric_limits<int>::is_integer);
static_assert(std::numeric_limits<double>::has_infinity);
int main() { return std::numeric_limits<int>::max() > 0 ? 0 : 1; }
```

## 常见陷阱

- 把浮点 `min()` 当作最负值，或把 `epsilon()` 直接用于任意幅值比较，都会造成错误边界判断。
- `lowest()`、`min()` 与 `denorm_min()` 含义不同；泛型代码在整数和浮点类型上不能机械套用同一边界。

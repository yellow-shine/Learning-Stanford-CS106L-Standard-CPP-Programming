# 17.8 类型别名（Type Aliases）

## 学习目标

用别名表达数值意图、简化泛型类型，同时清楚别名不会创建新类型。

## 核心知识点

- `using Name = T` 为既有类型提供另一拼写，可集中选择精度并减少复杂模板名称。
- 别名模板可保留模板参数，例如为固定元素类型定义容器族，但不会生成可独立重载的新类型。
- 平台宽度要求应优先采用 `<cstdint>` 的可选精确宽度类型或最小宽度类型。
- 若单位不能混用，单纯别名不够；应使用包装类，让类型系统拒绝错误运算。

## 最小示例

```cpp
#include <cstdint>
#include <vector>
using Sample = std::int32_t;
using Signal = std::vector<Sample>;
int main() { Signal s{1, 2, 3}; return s.size() == 3 ? 0 : 1; }
```

## 常见陷阱

- 误以为 `using Metres = double` 能阻止与秒相加；别名与底层类型完全相同，强语义需要新类型。
- 类型别名不会建立新的重载身份；不能分别为两个底层类型相同的单位别名提供不同函数重载。

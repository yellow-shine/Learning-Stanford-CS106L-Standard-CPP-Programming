# 17.9 数学常量（Mathematical Constants）

## 学习目标

使用 C++20 `<numbers>` 中类型化数学常量，避免不可移植宏与低精度手写值。

## 核心知识点

- `std::numbers::pi_v<T>`、`e_v<T>` 等变量模板按指定浮点类型提供实现可表示的常量。
- 便捷名称 `std::numbers::pi` 等价于 `double` 版本；高精度计算应显式选择 `long double`。
- 标准常量位于 `std::numbers`，使用前包含 `<numbers>`；`M_PI` 不是标准 C++ 保证的名称。
- 常量精度受目标类型限制，转成较窄类型不会保留额外数字。

## 最小示例

```cpp
#include <numbers>
constexpr double circumference(double r) {
    return 2.0 * std::numbers::pi * r;
}
static_assert(circumference(1.0) > 6.28);
int main() {}
```

## 常见陷阱

- 不要复制长串十进制常量或依赖平台宏；也不要把 `double` 常量先算完再期待赋给高精度类型恢复精度。
- `pi` 是 `double`，而 `pi_v<T>` 才按 `T` 实例化；先取窄类型常量再转换不会恢复已经舍入的精度。

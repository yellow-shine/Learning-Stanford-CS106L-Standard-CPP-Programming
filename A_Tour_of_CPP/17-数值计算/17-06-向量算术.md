# 17.6 向量算术（Vector Arithmetic）

## 学习目标

认识 `std::valarray` 的逐元素运算与切片能力，并了解它与通用容器的取舍。

## 核心知识点

- `valarray<T>` 面向数值数组，算术运算逐元素进行，表达式可由实现优化而少建临时对象。
- 同长度数组可相加、相乘；标量也能广播到各元素，但调用者仍应保证维度语义一致。
- `slice`、`gslice` 与掩码可选取元素集合，返回的代理具有特殊赋值和生命周期规则。
- 需要丰富容器接口、范围算法互操作或严格布局控制时，`vector` 配合算法往往更直观。

## 最小示例

```cpp
#include <cassert>
#include <valarray>
int main() {
    std::valarray<double> a{1.0, 2.0, 3.0};
    auto b = a * 2.0;
    assert(b[2] == 6.0);
}
```

## 常见陷阱

- 不要假定 `valarray` 代理就是普通引用，也不要把同长度误当作同单位；维度和物理单位仍需程序表达。
- 不要对长度不同的 `valarray` 直接做逐元素二元运算；先明确并检查维度，避免违反操作前置条件。

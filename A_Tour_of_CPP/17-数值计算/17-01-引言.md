# 17.1 引言（Introduction）

## 学习目标

建立标准数值设施的整体认识，能按精度、范围和性能要求选择类型与算法。

## 核心知识点

- 数值计算不仅是套用公式，还要明确表示范围、舍入规则、误差传播和溢出策略。
- 标准库以 `<cmath>`、`<numeric>`、`<complex>`、`<random>` 和 `<numbers>` 提供可移植构件。
- 整数运算精确但会溢出；浮点数范围宽，却通常只能近似表示十进制值。
- 先选择能表达问题的类型，再用测量决定是否需要并行化或专门数据布局。

## 最小示例

```cpp
#include <cmath>
#include <iostream>
int main() {
    double a{3}, b{4};
    std::cout << std::hypot(a, b) << '\n';
}
```

## 常见陷阱

- 把浮点相等、整数溢出或单位换算当作实现细节；数值边界必须成为接口设计的一部分。
- 同一公式在整数、浮点和复数类型上可能具有不同的定义域与误差行为；不要脱离数据模型选择表示。

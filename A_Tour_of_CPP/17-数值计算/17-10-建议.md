# 17.10 建议（Advice）

## 学习目标

形成数值程序的基本纪律：类型与单位先行，算法复用，误差和随机性显式。

## 核心知识点

- 优先使用标准数学函数和数值算法，它们比直接翻译公式更可能正确处理极端数量级。
- 为累加选择明确初值类型，检查整数范围，并根据数据尺度制定浮点比较策略。
- 随机代码保存种子与引擎配置以便复现；安全令牌则应使用专门的密码学随机设施。
- 以单位包装或领域类型阻止无意义组合，性能优化建立在代表性数据和基准测试上。

## 最小示例

```cpp
#include <algorithm>
#include <cmath>
bool close(double a, double b) {
    const double scale = std::max({1.0, std::abs(a), std::abs(b)});
    return std::abs(a - b) <= 1e-12 * scale;
}
int main() { return close(0.1 + 0.2, 0.3) ? 0 : 1; }
```

## 常见陷阱

- 固定绝对容差会在极大或极小数量级失效；具体容差必须来自业务误差预算，而非全局照抄。
- 数值代码通过编译不代表模型正确；还应验证边界输入、单位、误差和可复现性。

# 《A Tour of C++（第 3 版）》中文学习笔记

这是一份基于《A Tour of C++》第 3 版、以 C++20 为基准的原创学习提要。内容按概念重新概括，并配有可独立理解的最小示例。

第 14 章与第 18 章的小节目录编号已按内容顺序规范化（第 18 章“建议”为 18.7），便于连续阅读和导航。

> 本项目不是原书的替代品；建议结合正版原书、标准文档与实际编程练习学习。

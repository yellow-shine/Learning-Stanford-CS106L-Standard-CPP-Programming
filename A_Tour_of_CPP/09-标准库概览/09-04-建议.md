# 9.4 建议（Advice）

## 学习目标

形成优先复用标准组件、依据语义与成本选型的习惯，并在接口中明确所有权和失效规则。

## 核心知识点

- **优先复用**：标准组件经过广泛检验，通常比临时自制容器、字符串或同步原语更可靠且更易读。
- **按需选型**：默认顺序存储常用 `vector`；只有稳定节点、键查找或特殊复杂度需求才选择其他容器。
- **所有权表达**：值、智能指针、引用和视图表达不同生存期关系；接口应让所有权一目了然。
- **复杂度意识**：标准库给出渐近复杂度，但常数、缓存局部性及分配次数同样影响真实性能。
- **限定名称**：在公共代码中使用 `std::` 并直接包含所需头文件，减少隐式依赖。

## 最小示例

```cpp
#include <algorithm>
#include <string_view>
#include <vector>
bool has(std::vector<std::string_view> const& xs, std::string_view x) {
    return std::ranges::find(xs, x) != xs.end();
}
```

## 常见陷阱

- 不要仅凭“大 O 更好”选择链表或哈希表；先以真实数据测量。
- 不要用裸 `new` 管理本可由容器或智能指针拥有的资源。
- 不要为了统一风格强行包装标准 API，薄包装常只增加学习成本。

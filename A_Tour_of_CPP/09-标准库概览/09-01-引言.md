# 9.1 引言（Introduction）

## 学习目标

理解标准库如何以通用类型、算法和资源管理设施扩展核心语言，并能用组合而非重复造轮子解决常见问题。

## 核心知识点

- **标准库（standard library）**：由标准规定、随合规实现提供的组件集合；它不是语言语法，却是可移植 C++ 程序的基础。
- **容器（container）**：负责保存对象并管理其生存期，如 `vector`、`map`；不同容器提供不同复杂度保证。
- **算法（algorithm）**：通过迭代器或范围处理序列，使操作与具体容器解耦。
- **资源管理**：字符串、流、智能指针和线程等类型利用析构函数自动释放资源，体现 RAII。
- **组合使用**：标准类型共享约定，可把容器、算法、迭代器和 I/O 自然连接起来。

## 最小示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
int main() {
    std::vector<int> v{3, 1, 2};
    std::ranges::sort(v);
    for (int x : v) std::cout << x << ' ';
}
```

## 常见陷阱

- 不要把“标准库”误认为某个编译器的扩展；扩展接口未必可移植。
- 选择组件时应先看语义和复杂度，而非只看熟悉程度。
- 标准库不会替代边界检查、错误处理和并发同步等程序设计责任。

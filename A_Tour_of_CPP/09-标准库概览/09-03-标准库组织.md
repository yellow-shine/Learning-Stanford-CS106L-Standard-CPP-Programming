# 9.3 标准库组织（Standard-Library Organization）

## 学习目标

掌握头文件、命名空间和模块化使用方式，能够准确引入名称并避免污染作用域。

## 核心知识点

- **头文件（header）**：`#include <vector>` 等指令提供相应声明；使用组件应直接包含其规定头文件，不依赖间接包含。
- **命名空间（namespace）**：标准库名称主要位于 `std`；限定名能清晰表达来源并避免冲突。
- **标准头**：尖括号形式通常用于实现提供的头；头文件名与组件分组相关，而非保证一头一类型。
- **模块（module）**：C++20 提供语言模块机制，但标准库模块化接口在 C++20 中并未统一规定，支持情况依赖实现。
- **特化规则**：一般不得向 `std` 添加声明；仅少数标准明确允许的用户定义类型特化除外。

## 最小示例

```cpp
#include <string>
#include <vector>
int main() {
    std::vector<std::string> words{"C++", "20"};
    return words.size() == 2 ? 0 : 1;
}
```

## 常见陷阱

- 不要在头文件中写 `using namespace std;`，它会把冲突扩散到所有包含者。
- 间接包含并非接口承诺，缺少直接 `#include` 可能在换实现后失败。
- 不要把实验性的标准库模块支持当作可移植 C++20 功能。

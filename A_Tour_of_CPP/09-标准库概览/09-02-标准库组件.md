# 9.2 标准库组件（Standard-Library Components）

## 学习目标

识别标准库的主要组件类别，并理解泛型接口如何让数据结构、算法与资源设施协同工作。

## 核心知识点

- **语言支持**：类型信息、异常、初始化列表和比较类别等设施支撑高级抽象。
- **容器与算法**：容器保存元素，算法通过迭代器或范围访问元素；二者通常无需彼此了解具体类型。
- **字符串与正则**：`string` 管理字符序列，`string_view` 提供非拥有视图，`regex` 描述文本模式。
- **数值组件**：随机数、复数、数值算法和位操作服务于计算任务。
- **并发组件**：线程、锁、原子操作、条件变量及任务工具提供跨平台并发基础。
- **实用设施**：智能指针、时间、元组、可调用对象包装器和文件系统减少手写基础设施。

## 最小示例

```cpp
#include <numeric>
#include <vector>
int main() {
    std::vector<int> v{1, 2, 3};
    return std::accumulate(v.begin(), v.end(), 0) == 6 ? 0 : 1;
}
```

## 常见陷阱

- 算法的前置条件必须满足，例如排序要求可交换元素及适当的迭代器。
- `string_view`、迭代器和引用通常不拥有对象，必须关注被引用对象的生存期。
- 标准库实现可以不同，但可观察行为与复杂度保证应符合标准。

# 19.1 历史（History）

## 学习目标

了解 C++ 从“带类的 C”发展为现代多范式语言的主线，并用历史解释而非模仿旧习惯。

## 核心知识点

- C++ 起源于在系统编程效率基础上加入抽象机制，早期类、虚函数和运算符重载逐步形成核心。
- 标准化把语言与标准库置于共同规范下；后续版本在兼容既有代码的同时持续增加更安全的表达方式。
- RAII、泛型编程与零开销抽象贯穿演进，使资源安全和高层接口不必牺牲底层控制。
- 历史遗留语法仍可用不代表适合新代码；现代项目应按目标标准和工具链能力选择惯用法。

## 最小示例

```cpp
#include <memory>
#include <vector>
int main() {
    auto values = std::make_unique<std::vector<int>>(3, 7);
    return values->size() == 3 ? 0 : 1;
}
```

## 常见陷阱

- 把兼容性误解为应继续使用裸数组、宏和手工内存；理解旧代码很重要，新代码则应优先现代设施。
- 不能仅凭源码风格推断其语言版本；旧编译器扩展和后来改变的规则都可能影响真实语义。

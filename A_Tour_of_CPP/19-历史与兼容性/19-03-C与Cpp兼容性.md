# 19.3 C 与 C++ 兼容性（C/C++ Compatibility）

## 学习目标

理解两种语言的共同子集和 ABI 边界，安全复用 C 接口而不假定源码完全兼容。

## 核心知识点

- C++ 保留大量 C 语法和标准库接口，但两者是独立语言；有效 C 程序不保证也是有效或同义的 C++。
- `extern "C"` 指定 C 语言链接，便于链接按 C ABI 导出的函数；它不会把函数体改用 C 规则编译。
- 跨边界优先使用 C 可表示的整数、指针与显式长度，避免直接暴露 C++ 类、异常和模板。
- C 资源可由 C++ RAII 包装器接管，删除器调用原库释放函数，从而保证异常路径清理。

## 最小示例

```cpp
#include <cstdio>
#include <memory>
int main() {
    using File = std::unique_ptr<std::FILE, decltype(&std::fclose)>;
    File f{std::tmpfile(), &std::fclose};
    return f ? 0 : 1;
}
```

## 常见陷阱

- 不要用分配接口交叉释放，也不要让异常穿越不理解 C++ 异常的 C 回调或 ABI 边界。
- 不要假定同名 C 与 C++ 结构具有可交换布局；跨 ABI 只传双方明确约定的 C 兼容表示，并在边界内截获异常。

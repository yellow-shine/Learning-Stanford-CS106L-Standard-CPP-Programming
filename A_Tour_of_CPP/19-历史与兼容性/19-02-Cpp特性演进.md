# 19.2 C++ 特性演进（C++ Feature Evolution）

## 学习目标

建立主要标准版本的功能地图，正确区分可用版本并规划迁移。

## 核心知识点

- C++98/03 奠定标准语言、容器和算法基础；C++11 引入移动语义、lambda、线程与智能指针等现代核心。
- C++14/17 逐步完善推导、常量求值、结构化绑定、文件系统、`optional` 与 `variant`。
- C++20 加入概念、范围、协程、模块语言机制、`jthread`、`span` 和日历等设施。
- 编译选项声明目标标准，但库特性还取决于标准库版本；特性测试宏可比猜测编译器版本更精确。

## 最小示例

```cpp
#include <version>
#if !defined(__cpp_concepts) || __cpp_concepts < 201907L
#error "This example requires C++20 concepts"
#endif
#include <concepts>
template<std::integral T> T twice(T x) { return x+x; }
int main() { return twice(2)==4 ? 0 : 1; }
```

## 常见陷阱

- 不要因编译器接受某语法就假定所有目标环境可用；扩展模式与标准库缺失都可能破坏可移植性。
- `__cplusplus` 只说明语言模式，不保证相应库组件完整可用；库设施还应检查特性测试宏和目标实现。

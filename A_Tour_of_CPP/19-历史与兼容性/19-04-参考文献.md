# 19.4 参考文献（Bibliography）

## 学习目标

学会按问题类型选择权威资料，并核对标准版本、勘误与实现差异。

## 核心知识点

- ISO C++ 标准及其缺陷报告是语言和库行为的最终规范，但文本面向实现者，学习时可配合高质量参考资料。
- cppreference 等索引适合查询头文件、版本、复杂度与失效规则；教程摘要不能替代具体接口契约。
- 编译器和标准库发布说明用于确认模块、协程、格式化等新设施的实现状态。
- 核心指南、提案与会议论文解释设计动机，但提案版本不一定等同于最终标准措辞。

## 最小示例

```cpp
#include <iostream>
#include <version>
int main() {
    std::cout << "__cplusplus=" << __cplusplus << '\n';
}

```

## 常见陷阱

- 引用资料时遗漏版本会把 C++23 API 写进 C++20 代码；博客示例也可能依赖扩展、旧规则或未说明的库。
- 提案、博客和单个实现的文档不能覆盖最终标准；结论冲突时应核对已发布标准及适用的缺陷报告。

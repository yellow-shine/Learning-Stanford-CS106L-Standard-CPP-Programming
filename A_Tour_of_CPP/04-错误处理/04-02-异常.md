# 4.2 异常（Exceptions）

## 学习目标

理解抛出、栈展开与捕获的控制流，并利用 RAII 编写不会在异常路径泄漏资源的代码。

## 核心知识点

- **抛出（throw）**：创建异常对象并将控制转移到匹配的处理器，适合无法在当前层完成的失败。
- **栈展开（stack unwinding）**：寻找处理器时，已构造的自动对象按逆序析构，因此资源应由对象拥有。
- **异常处理器（catch handler）**：通常按 `const` 引用捕获，既避免复制也保留多态异常信息。
- **标准异常（standard exception）**：`std::runtime_error`、`std::invalid_argument` 等为常见错误提供统一基类 `std::exception`。
- **重新抛出（rethrow）**：在处理器内用不带操作数的 `throw;` 保留当前异常的动态类型。
- **不抛保证（noexcept）**：标明函数不允许异常逃逸；若仍逃逸会调用 `std::terminate`，不应仅为优化随意添加。

## 最小示例

```cpp
#include <stdexcept>
#include <string>

int parse_positive(const std::string& s) {
    int n = std::stoi(s);
    if (n <= 0) throw std::range_error{"not positive"};
    return n;
}
int main() {
    try { return parse_positive("0"); }
    catch (const std::exception&) { return 0; }
}
```

## 常见陷阱

- 按值捕获基类异常，造成对象切片并丢失派生信息。
- 从析构函数抛出异常，若正处于栈展开可能直接终止程序。
- 用异常处理正常、频繁且可预期的分支流程。

# 8.3 泛型编程（Generic Programming）

## 学习目标

从算法实际使用的操作提炼概念，并基于迭代器、范围和策略实现可组合的泛型算法。

## 核心知识点

- **抽象操作**：先找出算法依赖的最小能力，例如读取、递增和比较，再据此选择或定义概念。
- **迭代器（iterator）**：把遍历位置与容器表示分离，使同一算法可服务数组、链表及自定义序列。
- **范围（range）**：以首尾或 `begin`/`end` 表达序列，C++20 范围库进一步支持约束和视图组合。
- **投影与策略**：把比较、转换等变化点作为可调用参数传入，比复制整套算法更灵活。
- **多遍语义**：输入范围可能只能单遍读取；若算法需重复遍历，应要求更强的 `forward_range` 等概念。
- **复杂度契约**：泛型算法除类型正确外，还应说明次数级别与对参数操作复杂度的假设。

## 最小示例

```cpp
#include <concepts>
#include <functional>
#include <ranges>
template<std::ranges::input_range R, typename T, typename Proj = std::identity>
requires requires(Proj p, std::ranges::range_reference_t<R> x, const T& target) {
    { std::invoke(p, x) == target } -> std::convertible_to<bool>;
}
bool contains_by(R&& r, const T& value, Proj proj = {}) {
    for (auto&& x : r) if (std::invoke(proj, x) == value) return true;
    return false;
}
```

## 常见陷阱

- 默认假设可随机访问，会无意排除链表或输入流范围。
- 返回指向局部范围元素的迭代器或引用可能悬空，尤其当实参是临时对象时。
- 只检查语法而忽略等价关系、排序等语义，会让算法结果失去保证。

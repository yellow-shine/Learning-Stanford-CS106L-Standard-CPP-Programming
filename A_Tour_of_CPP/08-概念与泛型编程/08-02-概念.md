# 8.2 概念（Concepts）

## 学习目标

会定义和组合概念、书写 `requires` 表达式，并理解约束对模板可用性和重载解析的影响。

## 核心知识点

- **概念定义**：`template<...> concept C = 条件;` 定义产生 `bool` 的编译期谓词，不能显式特化。
- **requires 表达式**：在不执行代码的前提下检查表达式、类型、复合要求和嵌套约束是否成立。
- **简单要求**：只验证表达式有效；末尾分号不代表计算其值。
- **复合要求**：形如 `{ expr } -> Concept;`，可检查表达式有效性及返回类型约束。
- **约束组合**：可用 `&&`、`||` 组合已有概念；复用标准概念比重复底层表达式更能体现语义。
- **约束归一化**：编译器按约束结构判断哪个重载更受限；逻辑等价的手写布尔式未必形成预期包含关系。
- **简写约束**：`Concept auto` 可约束函数参数或推导变量，适合要求简单且局部的接口。

## 最小示例

```cpp
#include <concepts>
#include <cstddef>
template<typename T>
concept Sized = requires(const T& x) {
    { x.size() } -> std::convertible_to<std::size_t>;
};
template<Sized T>
bool empty(const T& x) { return x.size() == 0; }
```

## 常见陷阱

- `requires(T x) { x.f(); }` 不会真的构造 `T` 或调用 `f()`。
- 为获得可靠的偏序，应复用同一个基础概念，而非复制看似等价的表达式。
- 约束写得过强会排除本可工作的类型，写得过弱则把错误推迟到函数体。

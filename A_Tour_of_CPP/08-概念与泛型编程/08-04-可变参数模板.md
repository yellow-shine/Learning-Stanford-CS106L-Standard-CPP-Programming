# 8.4 可变参数模板（Variadic Templates）

## 学习目标

掌握参数包、包展开和折叠表达式，用少量代码处理类型或实参数量可变的场景。

## 核心知识点

- **参数包（parameter pack）**：`typename... Ts` 或 `Args&&... args` 表示零个或多个模板参数或函数参数。
- **包展开（pack expansion）**：含 `...` 的模式会对包中每个元素实例化一次，展开位置决定生成的语法结构。
- **折叠表达式（fold expression）**：把二元运算符应用到整个参数包，可指定初始值以正确处理空包。
- **包大小**：`sizeof...(Ts)` 在编译期得到元素数量，不会计算各实参。
- **可变参数约束**：可用折叠组合概念，例如 `(std::integral<Ts> && ...)` 要求每个类型都满足条件。
- **完美转发**：`Args&&...` 配合 `std::forward<Args>(args)...` 将每个实参的值类别传给下一层。
- **递归替代**：简单聚合优先用折叠表达式，避免递归模板的终止重载和更深实例化链。

## 最小示例

```cpp
#include <concepts>
template<std::integral... Ts>
constexpr auto sum(Ts... xs) {
    return (0LL + ... + xs);
}
int main() {
    static_assert(sum() == 0);
    static_assert(sum(1, 2, 3) == 6);
}
```

## 常见陷阱

- 没有初始值的一元折叠对空参数包可能不合法，应明确空包语义。
- `args...` 本身都是具名左值；转发时漏掉 `std::forward` 会丢失右值属性。
- 参数包适合真正的数量变化，不应用来绕过清晰的固定参数接口。

# 16.2 时间（Time）

## 学习目标

会用 `std::chrono` 表示时长与时点，并能为计时和日历任务选择合适时钟及转换方式。

## 核心知识点

- **时长（duration）**：由数值和编译期单位比例组成；不同单位间可进行受约束的安全转换。
- **时点（time_point）**：表示某个时钟纪元起的时长，只有同一时钟的时点才能直接相减。
- **稳定时钟**：`steady_clock` 单调不倒退，适合测量耗时；它不表示民用日期时间。
- **系统时钟**：`system_clock` 对应系统实时时钟，可与日历或 `time_t` 互操作，但可能被校时。
- **取整转换**：`duration_cast` 明确进行单位转换；`floor`、`ceil`、`round` 表达不同舍入策略。
- **日历支持**：C++20 `<chrono>` 定义 `year_month_day` 等日历类型，但格式化和时区数据库支持因实现而异。

## 最小示例

```cpp
#include <chrono>
#include <thread>
int main() {
    auto start = std::chrono::steady_clock::now();
    std::this_thread::sleep_for(std::chrono::milliseconds{1});
    auto elapsed = std::chrono::steady_clock::now() - start;
    return elapsed >= std::chrono::milliseconds{1} ? 0 : 1;
}
```

## 常见陷阱

- 不要用 `system_clock` 假定经过时间永远非负。
- 转成较粗单位会截断，比较前尽量保留原始精度。
- `sleep_for` 只保证至少等待到可调度条件，不能当作高精度实时定时器。

# 16.7 位操作（Bit Manipulation）

## 学习目标

掌握 C++20 无符号整数位运算、`<bit>` 工具和 `bitset`，避免移位与符号相关的未定义行为。

## 核心知识点

- **按位运算**：`&`、`|`、`^`、`~` 操作整数表示中的位，掩码代码优先使用无符号类型。
- **移位**：左、右操作数会整数提升；移位量为负或不小于类型位宽会产生未定义行为。
- **`<bit>`**：C++20 提供 `popcount`、`countl_zero`、`rotl`、`bit_width` 等无符号整数工具。
- **位转换**：`std::bit_cast` 在相同大小且满足条件的类型间复制对象表示，比指针重解释更安全。
- **`bitset`**：固定编译期位数的集合，支持测试、计数与逻辑运算，不依赖手写掩码。

## 最小示例

```cpp
#include <bit>
#include <bitset>
#include <cstdint>
int main() {
    std::uint32_t flags = 0b10110u;
    auto ones = std::popcount(flags);
    std::bitset<8> bits{flags};
    return ones == 3 && bits.test(2) ? 0 : 1;
}
```

## 常见陷阱

- 避免对负的有符号数做位移并假定跨平台结果。
- `1 << n` 的 `1` 是 `int`；宽掩码应写成合适无符号类型。
- `bit_cast` 不做数值转换，也不能绕过目标类型的有效表示要求。

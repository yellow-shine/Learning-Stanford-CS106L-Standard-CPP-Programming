# 16.8 退出程序（Exiting a Program）

## 学习目标

区分正常返回、`exit`、快速退出与异常终止的清理语义，并选择不会意外丢失资源的路径。

## 核心知识点

- **从 `main` 返回**：等价于以返回值调用正常终止流程；自动对象先按作用域正常销毁。
- **`std::exit`**：执行正常终止处理和已注册的 `atexit` 函数，但不会展开当前调用栈的自动对象。
- **`std::quick_exit`**：只执行 `at_quick_exit` 注册函数后终止，不执行普通完整清理。
- **`std::_Exit`**：立即终止，不调用清理处理程序；适合极少数无法安全清理的底层情形。
- **`std::terminate`**：异常无法继续处理等情况会调用终止处理器，默认导致异常终止。
- **退出状态**：`EXIT_SUCCESS`、`EXIT_FAILURE` 提供可移植状态值，具体外部编码由环境决定。

## 最小示例

```cpp
#include <cstdlib>
#include <iostream>
int main() {
    if (!std::cout) return EXIT_FAILURE;
    std::cout << "done\n";
    return EXIT_SUCCESS;
}
```

## 常见陷阱

- 在深层函数调用 `exit` 会跳过局部 RAII 对象析构，可能丢失缓冲数据或锁清理。
- 不要把 `terminate` 当作普通错误处理或用户输入校验。
- 快速退出不会承诺刷新所有流；关键数据应在退出前显式、安全地提交。

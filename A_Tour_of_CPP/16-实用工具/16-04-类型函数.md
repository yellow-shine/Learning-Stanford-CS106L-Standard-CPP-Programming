# 16.4 类型函数（Type Functions）

## 学习目标

会用类型特征和概念进行编译期查询、变换与约束，同时避免根据不可靠特征实现危险优化。

## 核心知识点

- **类型特征（type trait）**：`std::is_integral_v<T>` 等在编译期产生布尔值，位于 `<type_traits>`。
- **类型变换**：`remove_cvref_t`、`decay_t` 等生成相关类型，别名模板可减少冗长的 `typename`。
- **条件编译**：`if constexpr` 根据编译期条件丢弃不选分支，使一个模板安全处理不同类型。
- **概念优先**：公开模板约束常用标准概念比在函数体中静态断言更清晰，也更利于重载选择。
- **调用属性**：`is_invocable`、`invoke_result_t` 可检查调用是否合法及其结果类型。

## 最小示例

```cpp
#include <concepts>
#include <type_traits>
template<class T>
constexpr auto magnitude(T x) {
    if constexpr (std::is_signed_v<T>) return x < 0 ? -x : x;
    else return x;
}
static_assert(magnitude(-3) == 3);
static_assert(std::same_as<std::remove_cvref_t<const int&>, int>);
int main() {}
```

## 常见陷阱

- 某些特征要求完整类型；不要在不满足前置条件时查询。
- 类型特征描述语言属性，不保证某个平台上的性能。
- 手工特化标准库类型特征通常不被允许，除非标准明确开放该特化点。

# 16.3 函数适配（Function Adaption）

## 学习目标

掌握标准可调用对象包装与参数绑定工具，能在泛型、存储和成员调用场景中选择最小方案。

## 核心知识点

- **可调用对象（callable）**：函数、函数对象、lambda、成员指针均可通过统一调用语义使用。
- **`std::invoke`**：以一致方式调用普通函数或成员指针，并正确处理对象、引用包装器和指针。
- **`std::function`**：类型擦除任意兼容可调用对象，便于存储，但可能有间接调用与分配成本。
- **`std::bind_front`**：C++20 将前若干参数绑定为一个新可调用对象，通常比旧式 `bind` 更直观。
- **`std::mem_fn`**：把成员指针包装为普通可调用对象；不少算法中也可直接使用成员指针作投影。

## 最小示例

```cpp
#include <functional>
int add(int a, int b) { return a + b; }
struct X { int twice() const { return 2; } };
int main() {
    auto plus10 = std::bind_front(add, 10);
    X x;
    return plus10(3) == 13 && std::invoke(&X::twice, x) == 2 ? 0 : 1;
}
```

## 常见陷阱

- `std::function` 目标为空时调用会抛 `std::bad_function_call`。
- 绑定引用参数时需显式使用 `std::ref`，否则常会保存副本。
- lambda 足够时不要引入复杂 `bind` 占位符表达式。

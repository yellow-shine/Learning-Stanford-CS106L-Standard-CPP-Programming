# 16.1 引言（Introduction）

## 学习目标

认识标准库通用工具在时间、调用适配、类型查询、诊断和底层操作中的角色，并按语义选用。

## 核心知识点

- **通用设施**：`<chrono>`、`<functional>`、`<type_traits>`、`<source_location>` 等提供跨领域基础构件。
- **零开销抽象**：许多工具在编译期工作或仅包装现有对象，正确使用通常不引入不必要运行时成本。
- **类型安全**：时间单位、位集合和类型特征把原本依赖约定的整数或宏转换为可检查接口。
- **值类别**：`move` 与 `forward` 调整表达式类别，不执行资源搬运；真正行为由接收类型决定。
- **版本意识**：本章设施以 C++20 为基准；使用前仍要包含正确头文件并检查实现支持。

## 最小示例

```cpp
#include <chrono>
#include <iostream>
#include <source_location>
void log(std::source_location p = std::source_location::current()) {
    std::cout << p.line() << ' ' << std::chrono::seconds{1}.count() << '\n';
}
int main() { log(); }
```

## 常见陷阱

- 不要用无单位整数在接口间传递时间值。
- 类型工具不替代运行时验证；编译期信息无法判断外部输入是否合法。
- 底层工具看似简短，仍必须尊重寿命、溢出和线程安全规则。

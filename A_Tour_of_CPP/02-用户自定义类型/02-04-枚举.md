# 2.4 枚举（Enumerations）

## 学习目标

用枚举表示有限选项集合，并理解作用域枚举带来的类型安全及底层表示控制。

## 核心知识点

- **枚举（enumeration）**：为一组相关整数值提供有意义的命名，适合状态、模式和类别。
- **作用域枚举（scoped enum）**：`enum class` 的枚举项需经类型名限定，且不会隐式转换成整数。
- **底层类型（underlying type）**：可写成 `enum class E : unsigned char` 来控制表示；省略时由规则决定。
- **枚举值（enumerator）**：可显式指定常量值，未指定者通常在前一值基础上递增。
- **显式转换（explicit conversion）**：需要数值表示时可用 `static_cast`，转换应集中在协议或存储边界。
- **穷尽处理（exhaustive handling）**：`switch` 列出所有枚举项有助于编译器警告遗漏的新状态。

## 最小示例

```cpp
#include <string_view>

enum class Color { red, green, blue };
constexpr std::string_view name(Color c) {
    switch (c) {
    case Color::red: return "red";
    case Color::green: return "green";
    case Color::blue: return "blue";
    }
    return "unknown";
}
int main() { return name(Color::green) == "green" ? 0 : 1; }
```

## 常见陷阱

- 使用无作用域 `enum` 污染外围作用域，并发生意外整数转换。
- 假设任意底层整数转换后都对应已声明的枚举项。
- `switch` 添加 `default` 后，编译器可能无法提示新枚举项未处理。

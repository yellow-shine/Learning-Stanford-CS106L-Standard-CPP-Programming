# 2.3 类（Classes）

## 学习目标

使用类封装表示、建立不变量，并通过构造、成员访问和析构控制对象行为。

## 核心知识点

- **类（class）**：与 `struct` 能力基本相同，但成员及基类默认是 `private`，适合强调受控接口。
- **构造函数（constructor）**：创建对象时初始化成员并建立不变量；成员按声明顺序初始化，而非初始化列表书写顺序。
- **访问控制（access control）**：`public` 暴露接口，`private` 隐藏实现，`protected` 主要供派生类使用。
- **析构函数（destructor）**：对象生命周期结束时运行，用于释放其拥有的资源。
- **显式构造（explicit constructor）**：阻止单参数构造函数被意外用于隐式转换。
- **类内初始化器（default member initializer）**：为成员提供默认值，可由具体构造函数的初始化覆盖。

## 最小示例

```cpp
#include <stdexcept>

class Nonnegative {
    int n_{};
public:
    explicit Nonnegative(int n) : n_{n} {
        if (n < 0) throw std::invalid_argument{"negative"};
    }
    int get() const noexcept { return n_; }
};

int main() { return Nonnegative{2}.get() == 2 ? 0 : 1; }
```

## 常见陷阱

- 在构造函数体中才给成员赋值，导致成员先被默认初始化一次。
- 初始化列表顺序与声明顺序不同，引发依赖未初始化成员的问题。
- 暴露可修改的内部引用，使调用者绕过类的不变量。

# 2.2 结构体（Structures）

## 学习目标

掌握 `struct` 的聚合数据建模方式，并知道何时应从公开数据升级为受控类接口。

## 核心知识点

- **结构体（struct）**：可包含数据成员、成员函数和嵌套类型；成员及基类默认访问权限为 `public`。
- **聚合类型（aggregate type）**：满足规则的结构体可用成员顺序或 C++20 指定初始化器直接初始化。
- **成员访问（member access）**：对象使用 `.`，对象指针使用 `->` 访问成员。
- **成员函数（member function）**：可直接访问同一对象的成员；只读操作应加尾置 `const`。
- **数据布局（data layout）**：成员按声明顺序分配但可能含填充，不能把布局想当然地当作外部协议。
- **适用场景**：字段本身就是接口、组合关系简单且不存在复杂不变量时，公开结构体通常最清晰。

## 最小示例

```cpp
#include <cmath>

struct Point {
    double x{};
    double y{};
    double distance() const { return std::hypot(x, y); }
};

int main() {
    Point p{.x = 3, .y = 4};
    return p.distance() == 5 ? 0 : 1;
}
```

## 常见陷阱

- C++20 指定初始化器必须遵循成员声明顺序，且不能像 C 那样任意重排。
- 用 `memcpy`、逐字节比较处理含填充或非平凡成员的结构体。
- 当字段组合存在非法状态时仍保持全部公开。

# 11.1 引言（Introduction）

## 学习目标

理解 C++ I/O 以流、格式状态和缓冲为核心的模型，并能把同一读写逻辑用于控制台、文件与内存。

## 核心知识点

- **流（stream）**：流把值的格式化与具体设备解耦，程序通过统一接口读取或写入字符序列。
- **标准流**：`cin`、`cout`、`cerr` 和 `clog` 分别面向标准输入、标准输出及诊断输出。
- **格式化 I/O**：插入运算符 `<<` 把值转成文本，提取运算符 `>>` 从文本解析值。
- **状态驱动**：读写失败会设置状态位；流可在条件中测试，失败状态清除前后续操作通常不会成功。
- **RAII**：文件流对象管理文件句柄，离开作用域时自动关闭；仍应检查打开和写入结果。
- **缓冲**：输出往往先进入缓冲区，换行不总意味着立即刷新。

## 最小示例

```cpp
#include <iostream>
#include <sstream>
int main() {
    std::istringstream in{"12 30"};
    int a, b;
    if (in >> a >> b) std::cout << a + b << '\n';
}
```

## 常见陷阱

- 不检查输入结果会继续使用旧值或未得到有效数据。
- 不要误以为每个 `<<` 都立即触达终端或文件。
- 文本格式受区域设置和格式标志影响，协议格式应显式约定。

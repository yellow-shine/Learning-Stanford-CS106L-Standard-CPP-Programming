# 11.2 输出（Output）

## 学习目标

熟练使用流插入、换行与刷新，并理解输出表达式、缓冲和错误状态的实际行为。

## 核心知识点

- **插入运算符（insertion operator）**：`operator<<` 返回流引用，因此多个值可链式输出。
- **标准输出**：`std::cout` 用于普通结果；`std::cerr` 通常用于及时诊断，`std::clog` 更适合可缓冲日志。
- **换行与刷新**：`'\n'` 只插入换行字符；`std::endl` 还强制刷新，通常无需在每行使用。
- **缓冲区（buffer）**：缓冲减少系统调用；程序正常结束、显式 `flush` 或特定关联操作会触发刷新。
- **输出状态**：设备错误会设置流状态，必要时可测试 `if (!out)` 或启用异常掩码。

## 最小示例

```cpp
#include <iostream>
int main() {
    int n = 7;
    std::cout << "count=" << n << '\n';
    if (!std::cout) return 1;
}
```

## 常见陷阱

- 循环中滥用 `std::endl` 会产生不必要的刷新开销。
- `std::cerr` 的具体缓冲行为与流配置相关，不应代替显式持久化保证。
- 多线程同时写同一流时，单次操作可同步并不代表多段消息不会交错。

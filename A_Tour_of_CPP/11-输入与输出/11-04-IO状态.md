# 11.4 I/O 状态（I/O State）

## 学习目标

理解流的状态位及恢复步骤，能够区分正常文件结束、格式错误和严重设备故障。

## 核心知识点

- **良好状态（good state）**：`good()` 表示没有错误位；流的布尔转换主要判断是否设置 `failbit` 或 `badbit`。
- **文件结束**：`eofbit` 表示输入到达序列末尾，它可能与 `failbit` 同时设置。
- **格式失败**：`failbit` 常由无法把字符转换为目标类型引起，底层缓冲区通常仍可用。
- **严重错误**：`badbit` 表示流完整性受损，例如底层读写故障，通常不适合简单重试。
- **状态恢复**：`clear()` 重置状态位；若坏输入仍在序列中，还需 `ignore()` 或其他读取操作移除它。
- **异常掩码**：`exceptions(mask)` 可让指定状态触发 `std::ios_base::failure`，适合不能局部恢复的路径。

## 最小示例

```cpp
#include <iostream>
#include <limits>
int main() {
    int n;
    if (!(std::cin >> n)) {
        std::cin.clear();
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
        return 1;
    }
}
```

## 常见陷阱

- `eof()` 不是“下次读取是否会失败”的预测函数。
- 清状态而不消费非法输入会导致下一次提取再次失败。
- 开启异常后仍要区分 EOF、格式问题和不可恢复错误。

# 11.8 C 风格 I/O（C-style I/O）

## 学习目标

了解 `<cstdio>` 接口与 C++ 流的差异，能在兼容旧接口时避免格式串、缓冲和资源管理错误。

## 核心知识点

- **文件句柄**：`std::FILE*` 表示 C 流，`fopen` 成功后必须对应 `fclose`；失败返回空指针。
- **格式化函数**：`printf`、`fprintf` 的格式串决定可变参数解释方式，类型不匹配会产生未定义行为。
- **边界控制**：`snprintf` 接收缓冲区大小并返回本应写入的字符数，可用于检测截断。
- **二进制传输**：`fread`、`fwrite` 按元素读写原始字节；返回值是成功处理的元素个数。
- **错误检查**：返回值、`ferror` 与 `feof` 提供状态，文件结束与读取错误必须区分。
- **混用同步**：C 与 C++ 标准流默认同步；关闭同步后混合操作同一底层流的顺序可能不可预测。

## 最小示例

```cpp
#include <cstdio>
int main() {
    char buf[16];
    int n = std::snprintf(buf, sizeof buf, "%s:%d", "id", 7);
    return n >= 0 && n < static_cast<int>(sizeof buf) ? 0 : 1;
}
```

## 常见陷阱

- 不可信输入绝不能直接作为 `printf` 的格式串。
- `sprintf` 无长度参数，优先使用有边界的替代接口。
- 手工 `fclose` 容易在提前返回时遗漏，C++ 代码可用 RAII 包装所有权。

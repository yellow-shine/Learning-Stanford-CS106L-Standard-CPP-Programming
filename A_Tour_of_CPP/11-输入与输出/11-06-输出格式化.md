# 11.6 输出格式化（Output Formatting）

## 学习目标

使用流标志和操纵符控制数字、宽度与精度，并理解这些设置的持久性和作用范围。

## 核心知识点

- **操纵符（manipulator）**：`std::hex`、`std::fixed`、`std::boolalpha` 等修改流格式状态，许多设置会持续影响后续输出。
- **字段宽度**：`std::setw(n)` 只对紧随其后的一个格式化字段生效，不会永久保持。
- **浮点精度**：默认格式下 `setprecision` 控制有效数字；配合 `fixed` 时控制小数位数。
- **对齐与填充**：`left`、`right` 和 `setfill` 用于表格布局；填充字符通常保持到再次修改。
- **状态保存**：库函数若临时改变外部流，应保存并恢复标志、精度和填充字符，避免惊扰调用者。
- **现代格式化**：`std::format` 属于 C++20，但标准库实现支持度可能依工具链而异，且结果是字符串而非流状态。

## 最小示例

```cpp
#include <iomanip>
#include <iostream>
int main() {
    std::cout << std::fixed << std::setprecision(2)
              << std::setw(8) << 3.14159 << '\n';
}
```

## 常见陷阱

- 忘记恢复 `hex` 或 `fixed` 会让后续无关输出改变。
- `setw` 不会截断过长内容，也不会自动作用于整行。
- 金额不要用二进制浮点格式化来替代精确的业务表示。

# 11.3 输入（Input）

## 学习目标

正确使用格式化提取和逐行读取，并把输入成功与否纳入循环和解析逻辑。

## 核心知识点

- **格式化提取（formatted extraction）**：`>>` 按目标类型解析，默认跳过前导空白，遇到不合法文本时设置失败状态。
- **输入循环**：把提取表达式直接作为循环条件，可只处理成功读取的值并自然处理文件结束。
- **逐行读取**：`std::getline` 读取至分隔符并丢弃该分隔符，适合包含空格的完整行。
- **混合读取**：`>>` 常把结尾换行留在缓冲区，随后 `getline` 可能先得到空行。
- **字符读取**：`get` 默认不跳过空白；`peek` 查看但不提取下一个字符。
- **解析边界**：先读一行再用 `istringstream` 解析，可把一条记录的错误限制在该行。

## 最小示例

```cpp
#include <iostream>
#include <sstream>
#include <string>
int main() {
    std::string line;
    if (std::getline(std::cin, line)) {
        std::istringstream in{line};
        int n; if (in >> n) std::cout << n * 2 << '\n';
    }
}
```

## 常见陷阱

- 不要写 `while (!in.eof())`；EOF 只有尝试越过末尾后才设置。
- 混用 `>>` 与 `getline` 时要明确处理残留分隔符。
- 解析失败后仅 `clear()` 不会移走导致失败的字符。

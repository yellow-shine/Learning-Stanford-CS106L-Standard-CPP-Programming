# 11.9 文件系统（File System）

## 学习目标

使用 `std::filesystem` 以可移植方式表达路径、查询目录和执行常见文件操作，并正确处理错误与竞态。

## 核心知识点

- **路径（path）**：`std::filesystem::path` 表示平台相关路径语法，使用 `/` 运算符拼接路径比手写分隔符可靠。
- **查询操作**：`exists`、`is_regular_file`、`file_size` 等读取文件系统状态，可抛 `filesystem_error` 或通过 `error_code` 报错。
- **目录遍历**：`directory_iterator` 遍历一层，`recursive_directory_iterator` 递归遍历；顺序未作通用保证。
- **修改操作**：`create_directories`、`rename`、`copy`、`remove` 等直接影响外部状态，应检查结果。
- **路径分解**：`filename`、`stem`、`extension` 操作词法组成，不保证目标真实存在。
- **竞态条件**：先检查再操作之间文件系统可能变化，安全代码应以实际操作结果为准。

## 最小示例

```cpp
#include <filesystem>
#include <iostream>
int main() {
    namespace fs = std::filesystem;
    fs::path p = fs::current_path() / "data.txt";
    std::cout << p.filename().string() << '\n';
}
```

## 常见陷阱

- 不要把路径当作普通 UTF-8 `string` 在所有平台上处理。
- `exists(p)` 成功不保证下一步打开仍成功。
- 递归遍历需考虑权限错误、符号链接环和巨大目录树。

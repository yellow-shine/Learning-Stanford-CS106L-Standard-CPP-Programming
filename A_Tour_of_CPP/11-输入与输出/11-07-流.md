# 11.7 流（Streams）

## 学习目标

理解不同流类型共享的接口与缓冲层，并能在控制台、文件和字符串之间复用格式化逻辑。

## 核心知识点

- **流层次**：`istream`、`ostream` 和 `iostream` 分别提供输入、输出及双向接口，具体流复用这些基类协议。
- **字符串流（string stream）**：`istringstream` 与 `ostringstream` 在内存字符串上格式化，适合解析记录和构造消息。
- **文件流（file stream）**：`ifstream`、`ofstream`、`fstream` 绑定文件，并通过对象生存期管理句柄。
- **流缓冲（stream buffer）**：`streambuf` 负责字符传输与缓冲，格式化层把类型转换为字符。
- **开放模式**：`in`、`out`、`app`、`trunc`、`binary` 等标志决定文件行为，可按位组合。
- **可复用接口**：接受 `std::ostream&` 的函数可同时写终端、文件或字符串流。

## 最小示例

```cpp
#include <sstream>
#include <string>
void report(std::ostream& out, int n) { out << "n=" << n; }
int main() {
    std::ostringstream out;
    report(out, 5);
    return out.str() == "n=5" ? 0 : 1;
}
```

## 常见陷阱

- 文件打开失败不会必然抛异常，默认应检查流状态。
- 文本模式可能进行平台相关换行转换；二进制数据应使用 `binary`。
- 双向流切换读写方向时要遵守定位或同步要求。

# 7.1 引言（Introduction）

## 学习目标

理解模板如何把类型和值作为参数生成代码，并认识实例化、类型推导与约束在泛型代码中的角色。

## 核心知识点

- **模板（template）**：描述一族类、函数或变量，具体声明由模板参数替换后形成。
- **模板参数**：可以是类型、编译期值或模板本身；参数应代表算法真正需要变化的部分。
- **实例化（instantiation）**：编译器按实参生成具体实体，只有被使用的成员通常才需要完成语义检查。
- **函数模板推导**：调用时编译器可从函数实参推导模板实参，通常无需显式写尖括号参数。
- **编译期多态**：模板在编译时选择操作，无需虚调用，且可对不同表示生成专门代码。
- **约束（constraint）**：C++20 概念可明确模板对参数的要求，并改善重载选择和错误信息。

## 最小示例

```cpp
#include <concepts>
template<std::totally_ordered T>
constexpr const T& larger(const T& a, const T& b) {
    return b < a ? a : b;
}
int main() {
    static_assert(larger(3, 7) == 7);
    static_assert(larger(2.5, 1.0) == 2.5);
}
```

## 常见陷阱

- 模板并非“任意类型均可”；实现中使用的每个操作都会形成要求。
- 只在函数体深处触发错误会产生冗长诊断，公共模板应尽早添加约束。
- 模板定义若对实例化点不可见，常出现链接错误。

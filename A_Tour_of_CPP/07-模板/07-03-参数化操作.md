# 7.3 参数化操作（Parameterized Operations）

## 学习目标

用函数模板和函数对象参数化算法，并借助推导、lambda 与约束保持调用简洁。

## 核心知识点

- **函数模板（function template）**：把操作写成依赖参数类型的模式，调用时通常由实参自动推导类型。
- **可调用对象（callable）**：函数指针、带 `operator()` 的对象和 lambda 都可作为算法行为参数。
- **函数对象（function object）**：可携带状态并被内联优化，比固定函数指针更灵活。
- **泛型 lambda**：参数写为 `auto` 时，其调用运算符相当于模板，可用于局部、轻量的泛型操作。
- **返回类型推导**：`auto` 从返回表达式推导；多个返回路径必须产生兼容类型。
- **约束重载**：不同概念可选择不同算法版本，比在函数体中用类型判断更清楚。

## 最小示例

```cpp
#include <concepts>
#include <vector>
template<typename R, typename Pred>
requires requires(const R& r, Pred p) { r.begin(); r.end(); p(*r.begin()); }
int count_if(const R& r, Pred pred) {
    int n = 0;
    for (const auto& x : r) if (pred(x)) ++n;
    return n;
}
int main() { return count_if(std::vector{1,2,3,4}, [](int x){ return x%2==0; }); }
```

## 常见陷阱

- 按值接收大型函数对象或范围可能产生复制；按语义选择值、引用或转发引用。
- 推导不会普遍执行隐式转换来凑出同一个模板参数，混合类型调用可能失败。
- 自制算法前先检查标准库 `<algorithm>` 与 `<ranges>` 是否已有实现。

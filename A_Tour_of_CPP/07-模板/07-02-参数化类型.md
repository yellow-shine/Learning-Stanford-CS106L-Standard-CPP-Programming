# 7.2 参数化类型（Parameterized Types）

## 学习目标

设计类模板以复用数据结构，并掌握类型参数、非类型参数、成员定义和模板实参推导。

## 核心知识点

- **类模板（class template）**：以模板参数描述类型家族，例如 `Box<int>` 与 `Box<double>` 是不同的具体类型。
- **类型参数**：用 `typename` 或 `class` 引入，常用于元素类型、策略或回调对象类型。
- **非类型模板参数**：把编译期常量作为参数，例如固定容量；其值成为类型身份的一部分。
- **成员实例化**：类模板成员通常按需实例化，因此未使用的成员可具有额外操作要求。
- **类模板实参推导（CTAD）**：C++17 起可从构造实参推导类模板参数；必要时可提供推导指引。
- **别名模板**：`using` 可为复杂模板组合提供简短名称，但不会创建新类型。

## 最小示例

```cpp
#include <array>
#include <cstddef>
#include <stdexcept>
template<typename T, std::size_t N>
class Stack {
    std::array<T, N> data_{};
    std::size_t size_{};
public:
    void push(const T& x) {
        if (size_ == N) throw std::overflow_error{"full"};
        data_[size_++] = x;
    }
    const T& top() const { return data_.at(size_ - 1); }
};
int main() { Stack<int, 4> s; s.push(9); return s.top() == 9 ? 0 : 1; }
```

## 常见陷阱

- 固定容量满时必须检查；示例借 `at()` 抛异常，但实际接口还应定义容量语义。
- 不要把运行期才变化的值硬塞进非类型模板参数，否则会制造大量类型。
- 不同模板实参形成不同类型，不能直接互相赋值。

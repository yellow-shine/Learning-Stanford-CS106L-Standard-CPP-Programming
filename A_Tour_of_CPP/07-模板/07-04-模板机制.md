# 7.4 模板机制（Template Mechanisms）

## 学习目标

理解模板特化、`if constexpr`、折叠与依赖名称等机制，并只在确有必要时使用更复杂的元编程。

## 核心知识点

- **特化（specialization）**：为特定模板实参提供不同实现；函数模板通常优先采用重载而非部分特化技巧。
- **可变参数模板**：用参数包接收任意数量的模板实参，常配合折叠表达式处理。
- **编译期分支**：`if constexpr` 丢弃未选分支，使不同类型可使用不同但合法的代码路径。
- **依赖名称（dependent name）**：含义取决于模板参数的名称可能需要 `typename` 或 `template` 帮助解析。
- **变量模板**：为一族编译期值提供统一写法，标准库的类型特征常给出 `_v` 形式，便于组合条件。
- **完美转发（perfect forwarding）**：转发引用配合 `std::forward` 保留实参的左值、右值和限定属性。

## 最小示例

```cpp
#include <string>
#include <type_traits>
template<typename T>
std::string describe(const T& x) {
    if constexpr (std::is_integral_v<T>)
        return std::to_string(x);
    else
        return "non-integer";
}
int main() {
    return describe(42) == "42" ? 0 : 1;
}
```

## 常见陷阱

- 普通 `if` 的两个分支都须合法；依类型移除代码应使用 `if constexpr`。
- 在模板中漏写依赖类型前的 `typename` 会导致解析错误。
- 过度特化会形成难以预测的选择规则；约束重载通常更易维护。

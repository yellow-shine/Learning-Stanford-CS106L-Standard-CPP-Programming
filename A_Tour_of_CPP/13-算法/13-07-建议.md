# 13.7 建议（Advice）

## 学习目标

形成算法优先、契约先行的编码习惯，用标准设施替代易错的手写遍历。

## 核心知识点

- **表达意图**：优先写 `find_if`、`sort` 或 `transform`，让操作目的比循环控制细节更醒目。
- **最弱要求**：接口只要求真正需要的迭代器能力，能让代码覆盖更多容器与惰性范围。
- **契约检查**：使用有序算法前确认排序规则，写目标区间前确认容量，解引用前确认未到终点。
- **纯谓词**：尽量让谓词无副作用；算法可复制谓词并以未指定次数、次序调用它。
- **复杂度意识**：先选语义正确的算法，再依据数据规模与测量决定是否并行或换数据结构。

## 最小示例

```cpp
#include <algorithm>
#include <vector>
int main() {
    std::vector<int> v{-2, 1, -3, 4};
    std::erase_if(v, [](int x) { return x < 0; });
    std::ranges::sort(v);
    return v == std::vector<int>{1, 4} ? 0 : 1;
}
```

## 常见陷阱

- 不要为了“通用”把简单算法改写成复杂模板循环。
- 不要在没有基准数据时盲目加入并行策略。
- 算法名称不替代契约阅读，尤其要核对失效规则和返回值含义。

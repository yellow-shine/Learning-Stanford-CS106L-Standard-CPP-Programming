# 13.5 算法概览（Algorithm Overview）

## 学习目标

建立标准算法的功能地图，能按“查询、变换、重排、归约”快速找到合适工具。

## 核心知识点

- **非修改序列操作**：`find`、`count`、`equal`、`search` 观察元素而不改变序列。
- **修改操作**：`copy`、`transform`、`replace` 写入目标；必须预留空间或使用插入迭代器。
- **重排操作**：`sort`、`partition`、`rotate` 改变次序；稳定版本会保持等价元素的相对顺序。
- **有序序列操作**：`lower_bound` 与集合算法依赖既定排序规则，查询时必须使用兼容比较器。
- **堆算法**：`make_heap` 等在随机访问区间上维护堆结构，不会创建新容器。
- **数值算法**：`accumulate` 位于 `<numeric>`；初值类型影响整个归约的计算类型。

## 最小示例

```cpp
#include <algorithm>
#include <numeric>
#include <vector>
int main() {
    std::vector<int> v{3, 1, 2};
    std::ranges::sort(v);
    bool has2 = std::ranges::binary_search(v, 2);
    int sum = std::accumulate(v.begin(), v.end(), 0);
    return has2 && sum == 6 ? 0 : 1;
}
```

## 常见陷阱

- “remove-erase”中 `remove` 只搬移元素并返回新逻辑终点，不缩短容器。
- 二分查找用于未排序区间时违反前置条件。
- 用错误类型的归约初值可能发生截断，例如以 `0` 累加浮点数。

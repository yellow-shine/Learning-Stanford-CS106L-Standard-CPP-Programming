# 13.1 引言（Introduction）

## 学习目标

理解标准算法如何把“处理规则”与容器解耦，并能用迭代器或范围表达常见数据处理。

## 核心知识点

- **算法（algorithm）**：`<algorithm>` 提供查找、排序、复制、变换等通用操作，通常不拥有数据。
- **迭代器区间**：经典算法以 `[first,last)` 表示输入；尾迭代器不指向元素，空区间可由两端相等表示。
- **范围算法（ranges algorithm）**：C++20 的 `std::ranges` 重载可直接接收范围，并通过概念约束给出更清晰的错误。
- **复杂度**：选择算法时既看结果，也看比较、移动和额外存储成本；例如排序通常为 O(n log n)。
- **可组合性**：算法配合 lambda、投影和视图，可以避免重复手写循环并突出意图。

## 最小示例

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
int main() {
    std::vector<int> v{4, 1, 3, 2};
    std::ranges::sort(v);
    auto n = std::ranges::count_if(v, [](int x) { return x % 2 == 0; });
    std::cout << n << '\n';
}
```

## 常见陷阱

- 不要把 `last` 当作可解引用元素。
- 算法对迭代器失效规则没有豁免；操作容器结构后应重新取得迭代器。
- 先确认算法是否重排或覆盖输入，不能只凭名称猜测副作用。

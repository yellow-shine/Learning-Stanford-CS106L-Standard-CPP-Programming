# 13.2 迭代器的使用（Use of Iterators）

## 学习目标

掌握半开区间和输入/输出迭代器的基本用法，理解算法返回值如何连接后续处理。

## 核心知识点

- **半开区间**：`[begin,end)` 既自然表示空序列，也让元素数可写成距离，且便于拼接相邻区间。
- **迭代器（iterator）**：它把访问位置抽象为可递增、可解引用的对象，使同一算法适用于数组和多种容器。
- **输出迭代器**：`std::back_inserter` 把赋值转换为 `push_back()`，适合目标大小尚未确定的复制。
- **返回位置**：`find` 未找到时返回尾迭代器；先与 `end()` 比较，才能安全解引用。
- **范围版本**：`std::ranges::find(r,x)` 可省去重复端点；返回类型仍需留意借用范围与悬空保护。

## 最小示例

```cpp
#include <algorithm>
#include <iterator>
#include <vector>
int main() {
    std::vector<int> in{1, 2, 3}, out;
    std::ranges::copy(in, std::back_inserter(out));
    auto p = std::ranges::find(out, 2);
    return p != out.end() && *p == 2 ? 0 : 1;
}
```

## 常见陷阱

- `copy` 不会自动扩张普通目标迭代器指向的容器。
- 不同容器的迭代器不能组成一个合法区间或相互比较。
- 返回视图或局部容器的迭代器会悬空；必须明确所有者寿命。

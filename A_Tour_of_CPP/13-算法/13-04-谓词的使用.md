# 13.4 谓词的使用（Use of Predicates）

## 学习目标

会为查找、划分和排序提供满足契约的谓词，并理解捕获与投影的作用。

## 核心知识点

- **谓词（predicate）**：可调用对象接收算法元素并产生可按布尔值判断的结果。
- **一元谓词**：`find_if`、`count_if` 等对单个元素测试性质，不应依赖不可控的调用次数。
- **二元谓词**：排序比较器必须形成严格弱序；相等通常表示双方都不“小于”对方。
- **lambda 表达式**：可在调用处简洁定义规则；按引用捕获要求被捕获对象在调用期间仍存活。
- **投影（projection）**：范围算法可先取成员或转换值，再比较，避免为简单字段编写比较器。

## 最小示例

```cpp
#include <algorithm>
#include <string>
#include <vector>
struct User { std::string name; int age; };
int main() {
    std::vector<User> users{{"Li", 30}, {"An", 20}};
    std::ranges::sort(users, {}, &User::age);
    return users.front().name == "An" ? 0 : 1;
}
```

## 常见陷阱

- 不要用 `<=` 作为排序比较器；它不满足非自反性。
- 谓词修改参与比较的关键字段会破坏算法前提。
- 捕获局部变量引用的 lambda 若被保存到更长寿命处，会产生悬空引用。

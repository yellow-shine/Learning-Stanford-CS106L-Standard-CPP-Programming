# 13.3 迭代器类型（Iterator Types）

## 学习目标

区分主要迭代器类别，并依据算法需求选择能满足最弱约束的序列表示。

## 核心知识点

- **输入迭代器（input iterator）**：支持单向读取；多次遍历不一定有效，适合流式输入。
- **前向迭代器（forward iterator）**：可多趟遍历，同一位置的副本保持稳定语义。
- **双向迭代器（bidirectional iterator）**：增加递减能力，`list` 的迭代器是典型例子。
- **随机访问迭代器（random-access iterator）**：支持常数时间跳转、差值及次序比较，排序算法通常需要它。
- **连续迭代器（contiguous iterator）**：进一步保证元素连续存储，可与底层地址和 `span` 协作。
- **哨兵（sentinel）**：C++20 范围允许终点类型与迭代器不同，从而表达特殊终止条件。

## 最小示例

```cpp
#include <iterator>
#include <list>
#include <vector>
static_assert(std::random_access_iterator<std::vector<int>::iterator>);
static_assert(std::bidirectional_iterator<std::list<int>::iterator>);
static_assert(!std::random_access_iterator<std::list<int>::iterator>);
int main() {}
```

## 常见陷阱

- `list` 支持 `--`，却不支持 `it+n`，不能传给 `std::sort`。
- 迭代器类别描述能力，不保证实际访问缓存友好。
- 单趟输入迭代器被推进后，旧副本不应被假定仍可独立遍历。

# 15.4 替代方案（Alternatives）

## 学习目标

在采用指针容器前，能评估值、索引、引用包装和专用多态工具等更清晰的替代设计。

## 核心知识点

- **直接值存储**：若对象可复制或移动且不需运行时多态，`vector<T>` 通常最简单高效。
- **索引（index）**：以整数引用同一容器中的对象，序列化方便，也避免把内存地址暴露为身份。
- **引用包装器**：`reference_wrapper<T>` 可放入容器但不拥有对象，适用于明确且稳定的外部寿命。
- **判别联合**：有限类型集合可用 `variant` 代替继承与堆分配，并通过 `visit` 穷尽处理。
- **可选值**：可缺失的单个对象常用 `optional<T>`，无需用空指针编码存在性。

## 最小示例

```cpp
#include <string>
#include <variant>
#include <vector>
using Value = std::variant<int, std::string>;
int main() {
    std::vector<Value> v{42, std::string{"ok"}};
    return std::get<int>(v[0]) == 42 ? 0 : 1;
}
```

## 常见陷阱

- `reference_wrapper` 不延长对象寿命，不能包装即将消失的局部对象。
- 索引在擦除或重排后也可能失效；需要稳定句柄时应定义代次或映射策略。
- `variant` 适合封闭类型集合，不适合要求第三方随时扩展类型的接口。

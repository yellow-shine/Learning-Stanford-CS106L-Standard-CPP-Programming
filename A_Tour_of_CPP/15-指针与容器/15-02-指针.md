# 15.2 指针（Pointers）

## 学习目标

区分拥有与非拥有指针，在容器中安全表达独占、共享和可空引用关系。

## 核心知识点

- **裸指针（raw pointer）**：适合表示非拥有、可空观察者；它本身不说明对象由谁释放。
- **独占所有权**：`unique_ptr<T>` 不可复制但可移动，容器销毁或擦除元素时自动销毁对象。
- **共享所有权**：`shared_ptr<T>` 以引用计数共享寿命，只有确需共同拥有时使用。
- **弱引用**：`weak_ptr<T>` 不增加强引用计数，可打破共享指针环，并通过 `lock()` 临时取得所有权。
- **多态销毁**：经基类指针拥有派生对象时，基类析构函数通常必须为虚函数。

## 最小示例

```cpp
#include <memory>
#include <vector>
struct Base { virtual ~Base() = default; };
struct Item : Base {};
int main() {
    std::vector<std::unique_ptr<Base>> items;
    items.push_back(std::make_unique<Item>());
    Base* observer = items.front().get();
    return observer ? 0 : 1;
}
```

## 常见陷阱

- 不要用两个独立 `shared_ptr` 接管同一个裸指针，会导致重复释放。
- `get()` 返回值不转移所有权，所有者销毁后观察指针悬空。
- `shared_ptr` 环不会自动回收；至少一条反向关系应为 `weak_ptr`。

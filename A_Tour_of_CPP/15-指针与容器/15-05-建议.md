# 15.5 建议（Advice）

## 学习目标

建立“值优先、所有权显式、观察关系受控”的容器设计原则，减少泄漏与悬空访问。

## 核心知识点

- **值优先**：先尝试直接存值；仅在多态、共享寿命或地址稳定等具体需求出现时引入间接层。
- **独占优先**：必须动态拥有时优先 `unique_ptr`，它使所有者唯一且转移路径清楚。
- **共享审慎**：`shared_ptr` 表示共同负责寿命，而不是通用安全指针；观察关系用裸指针、引用或 `weak_ptr`。
- **工厂函数**：用 `make_unique`/`make_shared` 集中分配和构造，减少裸 `new` 暴露。
- **边界契约**：文档或类型应说明参数是否可空、是否转移所有权，以及返回观察者可存活多久。

## 最小示例

```cpp
#include <memory>
#include <vector>
struct Task { void run() {} };
int main() {
    std::vector<std::unique_ptr<Task>> tasks;
    tasks.emplace_back(std::make_unique<Task>());
    for (auto const& task : tasks) task->run();
}
```

## 常见陷阱

- 不要为了避免思考所有权而全部改成 `shared_ptr`。
- 不要从智能指针临时对象取得裸指针并长期保存。
- 删除拥有元素前，先确认系统中不存在仍会被使用的观察指针。

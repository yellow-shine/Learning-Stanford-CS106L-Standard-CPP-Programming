# 15.3 容器（Containers）

## 学习目标

能根据访问模式、所有权与稳定性要求选择指针容器，并正确执行插入、查找和删除。

## 核心知识点

- **值容器**：`vector<T>` 直接管理对象，避免额外分配和指针跳转，应优先考虑。
- **独占对象容器**：`vector<unique_ptr<T>>` 支持异质多态及稳定的被指对象地址，但容器本身不可复制。
- **关联容器**：键若为智能指针，默认比较的是指针所有者/地址语义，而非所指对象内容。
- **迭代失效**：容器重分配会使指向容器元素的指针、引用和迭代器失效；堆上被拥有对象可仍保持地址。
- **删除语义**：擦除智能指针元素会相应减少或终止所有权；裸观察者可能立刻悬空。

## 最小示例

```cpp
#include <memory>
#include <string>
#include <vector>
struct Node { std::string name; };
int main() {
    std::vector<std::unique_ptr<Node>> nodes;
    nodes.emplace_back(std::make_unique<Node>(Node{"root"}));
    Node* p = nodes[0].get();
    nodes.reserve(100);
    return p->name == "root" ? 0 : 1;
}
```

## 常见陷阱

- `reserve` 后容器内 `unique_ptr` 元素位置可变，但其所指对象通常未移动；两种地址不要混淆。
- 不能复制含 `unique_ptr` 的容器，需定义深复制或改用移动。
- 以裸指针作键时，默认排序/散列通常按地址，不按对象值。

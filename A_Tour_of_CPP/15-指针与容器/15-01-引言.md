# 15.1 引言（Introduction）

## 学习目标

理解指针与容器的组合如何表达对象关系，并优先用所有权明确、迭代安全的现代 C++ 设计。

## 核心知识点

- **值语义（value semantics）**：容器直接保存对象最简单，复制容器也复制元素，通常应作为默认方案。
- **间接存储**：保存指针适用于多态、共享对象或地址稳定需求，但必须明确所有者与观察者。
- **资源管理**：智能指针将释放动作绑定到对象寿命，避免手工 `new`/`delete` 分散在控制流中。
- **连续容器**：`vector` 通常具有良好局部性；元素类型可移动时，扩容会迁移元素。
- **算法接口**：无论元素是值还是指针，均可通过迭代器、范围、投影统一处理。

## 最小示例

```cpp
#include <algorithm>
#include <memory>
#include <vector>
int main() {
    std::vector<std::unique_ptr<int>> v;
    v.push_back(std::make_unique<int>(3));
    v.push_back(std::make_unique<int>(1));
    std::ranges::sort(v, {}, [](auto const& p) { return *p; });
    return *v.front() == 1 ? 0 : 1;
}
```

## 常见陷阱

- 裸指针容器不会自动删除所指对象。
- 智能指针解决寿命，不自动解决并发访问或逻辑别名问题。
- 为地址稳定而放弃 `vector` 前，应确认真实需求并评估替代索引方案。

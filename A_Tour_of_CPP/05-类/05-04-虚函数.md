# 5.4 虚函数（Virtual Functions）

## 学习目标

掌握虚调用、覆盖与动态类型之间的关系，并正确使用 `override`、`final` 和虚析构函数。

## 核心知识点

- **虚函数（virtual function）**：允许派生类提供覆盖实现，经基类引用或指针调用时动态分派。
- **覆盖（override）**：派生函数须与基类虚函数签名匹配；`override` 能让编译器检查是否真正覆盖。
- **动态类型（dynamic type）**：表达式的静态类型在编译期已知，而其引用对象的实际类型决定虚调用目标。
- **终结覆盖（final）**：可禁止函数继续被覆盖，或禁止类继续派生，适合表达明确的设计边界。
- **纯虚与默认实现**：纯虚函数要求派生类覆盖；普通虚函数则可提供可复用的默认行为。
- **构造析构期间的分派**：此时虚调用只到当前正在构造或析构的类，不会进入尚未建立或已被销毁的派生部分。

## 最小示例

```cpp
#include <iostream>
struct Animal {
    virtual void speak() const { std::cout << "?"; }
    virtual ~Animal() = default;
};
struct Dog final : Animal {
    void speak() const override { std::cout << "woof"; }
};
void announce(const Animal& a) { a.speak(); }
int main() { Dog d; announce(d); }
```

## 常见陷阱

- 签名中的 `const`、引用限定或参数不同会形成隐藏而非覆盖；始终写 `override`。
- 不要依赖构造函数中的虚调用触达派生类实现。
- 多态基类通常不应公开复制操作，否则容易诱发切片。

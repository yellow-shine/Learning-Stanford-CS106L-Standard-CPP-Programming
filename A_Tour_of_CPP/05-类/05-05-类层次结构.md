# 5.5 类层次结构（Class Hierarchies）

## 学习目标

能用类层次结构表达“是一个”的关系，并组合接口继承、实现复用和受控向下转换。

## 核心知识点

- **类层次结构（class hierarchy）**：通过派生关系组织相关类型，使代码可面向共同基类操作。
- **公有继承（public inheritance）**：表达派生对象可替代基类对象；若只是复用实现，组合通常更合适。
- **接口继承**：继承抽象操作约定，让不同实现由同一调用代码使用。
- **实现继承**：复用基类数据或函数，但会增加耦合，应避免让派生类依赖脆弱的表示细节。
- **受保护成员（protected member）**：向派生类开放而对外隐藏；优先使用受保护操作而非直接暴露数据。
- **运行时类型识别（RTTI）**：`dynamic_cast` 可安全检查多态对象的具体类型，但频繁使用常提示接口缺少所需操作。

## 最小示例

```cpp
#include <memory>
#include <vector>
struct Node { virtual int value() const = 0; virtual ~Node() = default; };
struct Number : Node {
    int n;
    explicit Number(int x) : n{x} {}
    int value() const override { return n; }
};
int sum(const std::vector<std::unique_ptr<Node>>& xs) {
    int r = 0; for (auto& x : xs) r += x->value(); return r;
}
```

## 常见陷阱

- 用继承表达“有一个”关系会导致不必要耦合；成员组合更直接。
- 基类缺少虚析构函数时，拥有派生对象的基类智能指针不能安全销毁它。
- 深层层次结构难以理解；优先保持接口小、层次浅。

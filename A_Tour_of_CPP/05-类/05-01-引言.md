# 5.1 引言（Introduction）

## 学习目标

理解类如何把数据、操作与不变量组合成用户自定义类型，并能区分接口与实现。

## 核心知识点

- **类（class）**：以成员为单位描述对象的状态和行为，是建立新类型的主要工具。
- **封装（encapsulation）**：用访问控制隐藏表示，只让调用者通过公开接口操作对象，避免任意状态组合。
- **不变量（invariant）**：对象在公开操作前后都应满足的条件；构造函数负责建立它，成员函数负责维护它。
- **成员函数（member function）**：可访问对象成员；尾部 `const` 表示不会经由该对象修改其可观察状态。
- **接口与实现**：公开成员表达使用方式，私有成员保存表示细节；二者分离可降低修改影响。

## 最小示例

```cpp
#include <stdexcept>
class Percent {
    int value_;
public:
    explicit Percent(int v) : value_{v} {
        if (v < 0 || v > 100) throw std::out_of_range{"percent"};
    }
    int value() const { return value_; }
};
int main() { Percent p{80}; return p.value() == 80 ? 0 : 1; }
```

## 常见陷阱

- 仅把字段改为 `private` 并不自动形成良好封装；接口仍须维护清晰的不变量。
- 忘记为只读成员函数添加 `const`，会导致常量对象无法调用。
- 构造后再调用初始化函数会留下“尚未有效”的中间状态。

# 5.3 抽象类型（Abstract Types）

## 学习目标

理解抽象类型如何只承诺接口而隐藏表示，并用纯虚函数表达可替换的实现。

## 核心知识点

- **抽象类型（abstract type）**：至少含一个纯虚函数，不能直接实例化，只能通过引用或指针使用其派生对象。
- **纯虚函数（pure virtual function）**：以 `=0` 声明必须由具体派生类实现的操作。
- **运行时多态（runtime polymorphism）**：经基类引用或指针调用虚函数时，根据对象的动态类型选择实现。
- **抽象接口**：应聚焦稳定的行为约定，不向使用者泄漏存储结构或具体算法。
- **虚析构函数**：若对象可能经基类指针销毁，基类析构函数必须为虚函数，才能完整析构派生部分。
- **所有权**：接口指针不自动说明谁负责销毁；拥有对象时通常用 `std::unique_ptr` 明示独占所有权。

## 最小示例

```cpp
#include <memory>
struct Shape {
    virtual double area() const = 0;
    virtual ~Shape() = default;
};
class Square final : public Shape {
    double side_;
public:
    explicit Square(double s) : side_{s} {}
    double area() const override { return side_ * side_; }
};
int main() { std::unique_ptr<Shape> s = std::make_unique<Square>(3); }
```

## 常见陷阱

- 按值传递基类会发生对象切片，派生状态与多态行为都会丢失。
- 省略虚析构函数后经基类指针 `delete` 派生对象会产生未定义行为。
- 不要让接口返回依赖具体实现生命周期的悬空引用。

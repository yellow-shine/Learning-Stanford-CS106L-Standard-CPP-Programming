# 5.2 具体类型（Concrete Types）

## 学习目标

掌握值语义具体类型的基本设计：对象可直接创建、复制并高效访问其表示，同时始终保持有效状态。

## 核心知识点

- **具体类型（concrete type）**：表示布局完整可知，通常能直接创建对象并按值使用。
- **值语义（value semantics）**：复制得到独立且等值的对象，使用体验类似内置数值类型。
- **构造函数（constructor）**：把原始参数转换为满足不变量的对象；失败时应抛出异常而非留下半成品。
- **访问控制**：`private` 隐藏表示，`public` 提供稳定操作；`struct` 与 `class` 的主要语言差别是默认访问权限。
- **成员初始化列表**：在进入构造函数体前直接初始化成员，适用于常量、引用以及无默认构造的成员。
- **类内定义**：短小成员函数可直接写在类定义中，通常会成为内联候选，但不保证机器码一定内联。

## 最小示例

```cpp
#include <numbers>
struct Point { double x, y; };
class Circle {
    Point center_;
    double radius_;
public:
    Circle(Point c, double r) : center_{c}, radius_{r} {
        if (!(r >= 0)) throw "negative radius";
    }
    double area() const { return std::numbers::pi * radius_ * radius_; }
};
```

## 常见陷阱

- 暴露可写引用或指针可能绕过检查，破坏私有表示的不变量。
- 成员实际按声明顺序初始化，而不是按初始化列表的书写顺序。
- 不要为简单值类型无故使用堆分配；直接成员通常更清晰、更高效。

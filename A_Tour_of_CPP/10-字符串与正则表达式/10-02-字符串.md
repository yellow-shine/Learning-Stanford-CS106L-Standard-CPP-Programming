# 10.2 字符串（Strings）

## 学习目标

掌握 `std::string` 的所有权、常用修改与查找操作，并理解引用和迭代器何时失效。

## 核心知识点

- **值语义（value semantics）**：字符串复制后各自拥有内容；移动通常可转移内部资源，但移后对象只保证有效、状态未指定。
- **连续存储**：字符连续排列，`data()` 可用于与接收长度的底层接口交互，C++17 起非 const 对象可取得可写指针。
- **拼接与追加**：`+` 生成结果，`+=` 与 `append` 修改原对象；大量拼接可先 `reserve` 减少重分配。
- **查找**：`find` 返回位置或 `std::string::npos`，它不是负数。
- **访问**：`operator[]` 不检查范围，`at()` 越界时抛出 `std::out_of_range`。
- **C 字符串接口**：`c_str()` 提供以空字符结尾的只读表示，其指针可能在修改后失效。

## 最小示例

```cpp
#include <string>
int main() {
    std::string s = "C++";
    s += "20";
    auto p = s.find("++");
    return p == 1 && s.at(3) == '2' ? 0 : 1;
}
```

## 常见陷阱

- 保存 `data()`、引用或迭代器后再修改字符串，可能因重分配产生悬空访问。
- `size()` 返回无符号 `size_type`，避免与负数直接比较。
- 内嵌 `\0` 是合法内容；只依赖 C 接口会过早截断。

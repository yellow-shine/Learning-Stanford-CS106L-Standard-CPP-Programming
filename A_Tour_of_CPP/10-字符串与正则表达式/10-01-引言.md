# 10.1 引言（Introduction）

## 学习目标

区分拥有字符数据的字符串、非拥有视图和模式匹配工具，并为具体文本任务选择最低成本的抽象。

## 核心知识点

- **字符串（string）**：`std::string` 拥有可变字符序列，自动管理存储并提供查找、拼接和比较操作。
- **字符串视图（string view）**：`std::string_view` 只描述连续字符区间，复制便宜但不延长底层数据寿命。
- **正则表达式（regular expression）**：`std::regex` 表示模式，可用于搜索、匹配与替换复杂文本结构。
- **字符编码**：标准字符串本质上是代码单元序列；`size()` 不保证等于用户感知字符数。
- **选择原则**：需要所有权或修改时用 `string`，只读参数可考虑 `string_view`，简单查找不必升级为正则。

## 最小示例

```cpp
#include <iostream>
#include <string>
#include <string_view>
int main() {
    std::string s = "modern C++";
    std::string_view v = s;
    std::cout << v.substr(7) << '\n';
}
```

## 常见陷阱

- 不要让视图指向已销毁或已重新分配的字符串。
- 不要假定 UTF-8 的一个字节就是一个字符。
- 对固定字面量搜索使用 `find` 往往比正则更直接。

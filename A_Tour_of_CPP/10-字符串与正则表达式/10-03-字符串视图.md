# 10.3 字符串视图（String Views）

## 学习目标

用 `std::string_view` 实现低开销只读文本接口，同时正确处理生存期、终止符和子视图。

## 核心知识点

- **非拥有视图（non-owning view）**：视图保存指针和长度，构造与复制通常是常数时间，不分配字符存储。
- **通用参数**：它可同时接收字符串字面量、`std::string` 和字符区间，适合不保留参数的只读函数。
- **子视图**：`substr` 产生另一视图而不复制字符；`remove_prefix`、`remove_suffix` 仅调整当前视图边界。
- **长度语义**：视图可包含空字符，也不保证末尾紧接 `\0`；传给 C API 前通常需复制成字符串。
- **比较与查找**：接口类似字符串，但不能增删或改写底层字符。

## 最小示例

```cpp
#include <string_view>
constexpr std::string_view extension(std::string_view p) {
    auto i = p.rfind('.');
    return i == p.npos ? std::string_view{} : p.substr(i);
}
static_assert(extension("a.cpp") == ".cpp");
int main() {}
```

## 常见陷阱

- 不要返回指向函数内局部 `std::string` 的视图。
- `std::string_view(std::string{"tmp"})` 在完整表达式结束后即悬空。
- `view.data()` 不等于可安全传给所有要求空终止字符串的函数。

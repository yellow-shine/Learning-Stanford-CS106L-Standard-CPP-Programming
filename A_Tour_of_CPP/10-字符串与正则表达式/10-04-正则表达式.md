# 10.4 正则表达式（Regular Expressions）

## 学习目标

能够构造并应用 `std::regex` 完成整串匹配、局部搜索和捕获，同时认识其错误与性能边界。

## 核心知识点

- **模式对象**：`std::regex` 编译文本模式；默认语法为修改后的 ECMAScript，可用标志选择其他标准语法。
- **整串匹配**：`std::regex_match` 要求输入整体符合模式，适合验证完整字段。
- **局部搜索**：`std::regex_search` 查找首个匹配子序列，适合从较长文本中提取信息。
- **匹配结果**：`std::smatch` 保存完整匹配与捕获组；其子匹配引用原输入，输入必须仍然有效。
- **错误报告**：非法模式构造时抛出 `std::regex_error`，外部提供的模式应捕获并报告。
- **替换**：`std::regex_replace` 根据格式串生成新文本，不原地修改输入。

## 最小示例

```cpp
#include <regex>
#include <string>
int main() {
    std::string s = "id=42";
    std::smatch m;
    std::regex r{R"(id=(\d+))"};
    return std::regex_match(s, m, r) && m[1] == "42" ? 0 : 1;
}
```

## 常见陷阱

- 原始字符串字面量可减少反斜杠的双重转义。
- 不可信复杂模式可能消耗大量时间；标准接口不提供统一超时机制。
- 简单分隔、前缀或固定子串任务通常无需正则。
